## 煮出醪量

*Kunze p.244–245* · 用于 [3.2 糖化](03-wort-production.md#s3-2)

煮出醪量 = 升温幅度 × 总醪量 ÷（90 °C − 未煮醪温度）。90 °C 是煮沸醪泵回时考虑降温后的有效温度；经验值约为总醪的 1/4–1/3。书中 p.245 示例的算术有排印错误，按公式应为 45.5 hl。

| 输入 | 示例值 |
| --- | --- |
| 总醪量 | 120 hl |
| 未煮醪（休止）温度 | 50 °C |
| 回混后目标温度 | 64 °C |
| 煮沸醪回混时的有效温度 | 90 °C |

| 结果 | 示例输出 |
| --- | --- |
| 需煮沸的稠醪 | 42.0 hl |
| 占总醪 | 35 % |
| 留在锅里不煮 | 78.0 hl |

## 投料水与头道麦汁浓度

*Kunze p.234–235* · 用于 [3.2 糖化](03-wort-production.md#s3-2)

经验法则：100 kg 粉 + 3 hl 水 ≈ 20% 头道麦汁，水量与目标浓度成反比；粉的体积按约 0.7 hl/100 kg 计。头道麦汁一般比成品原麦汁高 4–6%，淡色啤酒常用 3–4 hl/100 kg。

| --- | --- |
| 投料（粉） | 3000 kg |
| 目标头道麦汁浓度 | 18 % |

| 结果 | 示例输出 |
| --- | --- |
| 投料水 | 100.0 hl |
| 醪体积约 | 121.0 hl |
| 料水比 | 3.3 L/kg |

## 酒花添加量

*Kunze p.320–321* · 用于 [3.5 麦汁煮沸与加酒花](03-wort-production.md#s3-5)

BU = 每升啤酒中苦味物的毫克数；按冷麦汁体积（热体积 × 0.96）计算。苦味收率一般 25–35%，要在自己的厂里试验确定：需加入的 α-酸克数大约是目标 BU 值的 1/3（每 hl）。苦型酒花先加，香型酒花后加。

| 输入 | 示例值 |
| --- | --- |
| 目标苦味 | 30 BU |
| 热定型麦汁 | 200 hl |
| 苦味收率（按成品） | 30 % |
| 产品 A 承担的比例 | 70 % |
| 产品 A 的 α-酸 | 12 % |
| 产品 B 的 α-酸 | 5 % |

| 结果 | 示例输出 |
| --- | --- |
| 冷定型麦汁 | 192.0 hl |
| 进入啤酒的苦味物 | 576 g |
| 需加入的 α-酸 | 1.92 kg |
| 产品 A | 11.2 kg |
| 产品 B | 11.5 kg |

## 糖化间收率与发酵间收率

*Kunze p.323–331、398–399* · 用于 [3.6 糖化间收率](03-wort-production.md#s3-6)

收率 = 浸出物(kg/hl) × 0.96 × 热定型量 ÷ 投料。kg/hl 由 °P 乘以 20/4 °C 比重得到，即书中 Plato 表的“g/100 mL”一栏；0.96 是热麦汁冷到 20 °C 的收缩系数。接种麦汁是冷的，不再乘 0.96。正常糖化间收率 74–79%。

| 输入 | 示例值 |
| --- | --- |
| 投料 | 4000 kg |
| 热定型麦汁 | 262 hl |
| 定型麦汁浓度 | 11.6 °P |
| 接种麦汁（冷） | 254 hl |
| 接种麦汁浓度 | 11.4 °P |

| 结果 | 示例输出 |
| --- | --- |
| 浸出物（20 °C） | 12.12 kg/hl |
| 收率因子 | 11.64 |
| 糖化间浸出物 | 3,048 kg |
| 糖化间收率 | 76.21 % |
| 发酵间收率 | 75.57 % |
| 定型→接种损失 | 25 kg 浸出物 |

## 表观与真实发酵度

*Kunze p.403–406* · 用于 [4.4 常规发酵与贮酒](04-fermentation.md#s4-4)

转罐时一般希望与极限相差约 10 个百分点（约 1% 浸出物），留给贮酒罐里的后发酵产生 CO₂；灌装前的最终发酵度则应尽量接近极限，否则等于给微生物留了糖。真实发酵度 ≈ 0.81 × 表观发酵度（Balling 经验系数）。

| 输入 | 示例值 |
| --- | --- |
| 原麦汁（接种麦汁） | 12 °P |
| 当前表观浸出物 | 3.8 °P |
| 发酵度极限对应的浸出物 | 2.1 °P |

| 结果 | 示例输出 |
| --- | --- |
| 表观发酵度 Vs | 68.3 % |
| 真实发酵度 ≈ | 55.4 % |
| 发酵度极限 | 82.5 % |
| 与极限相差 | 14.2 个百分点 |
| 残余可发酵浸出物 | 1.7 °P |

<a id="blend"></a>

## 调配（混合十字）

*Kunze p.408–409* · 用于 [4.4 常规发酵与贮酒](04-fermentation.md#s4-4)

混合十字：把两种液体的浸出物写在左侧、目标写在中间，交叉相减得到两者的份数；混合方程 V1·E1 + V2·E2 =（V1+V2）·Et 给出同样结果。按百分数计算是近似，严格计算应换成 20/4 °C 密度；而且两种液体很难真正混匀。

| 输入 | 示例值 |
| --- | --- |
| 啤酒（麦汁）A 的量 | 500 hl |
| A 的浸出物 | 12.4 % |
| B 的浸出物（水填 0） | 0 % |
| 目标浸出物 | 11.6 % |

| 结果 | 示例输出 |
| --- | --- |
| 需加入 B | 34.5 hl |
| 调配后总量 | 534.5 hl |
| A : B | 11.6 : 0.8 |

## CO₂ 溶解量

*Kunze p.409–410* · 用于 [4.4 常规发酵与贮酒](04-fermentation.md#s4-4)

亨利定律：溶解量 ≈ 该温度下常压溶解度 × 绝对压力（按书中做法，常压取 1 bar）。常压溶解度取书中 12 °P、发酵度 80% 啤酒的数值并线性插值，0 °C 以下为外推。灌装的啤酒应含约 0.5% CO₂。

| 输入 | 示例值 |
| --- | --- |
| 啤酒温度 | 1 °C |
| 罐压（表压） | 0.5 bar |
| 目标 CO₂ 含量 | 0.5 % |

| 结果 | 示例输出 |
| --- | --- |
| 饱和 CO₂ 含量 | 0.459 % |
| 约合 | 4.6 g/L |
| 该温度常压溶解度 | 0.306 % |
| 达到目标所需表压 | 0.63 bar |

> 提示：低于 0.50%：灌装途中还会损失一些，贮酒时宜再高一点。

## 接种量

*Kunze p.400、438* · 用于 [4.4 常规发酵与贮酒](04-fermentation.md#s4-4)

常用接种量 20–30×10⁶ 个/mL，约相当于每 hl 0.6–1 L 浓酵母泥（泥约 3×10⁹ 个/mL）。提高接种量是加快发酵而不带来负面后果的最重要手段，也能减少高级醇。

| 输入 | 示例值 |
| --- | --- |
| 目标细胞浓度 | 25 ×10⁶/mL |
| 酵母泥浓度 | 3 ×10⁹/mL |
| 麦汁量 | 500 hl |

| 结果 | 示例输出 |
| --- | --- |
| 每 hl 酵母泥 | 0.83 L |
| 总共需要 | 417 L |

<a id="ccv"></a>

## 锥形罐容积与顶空

*Kunze p.417–419、426* · 用于 [4.5 锥形罐发酵与成熟](04-fermentation.md#s4-5)

锥部 V = πr²h/3，筒体 V = πr²h；锥角 60° 时锥高 ≈ 0.866 × 直径。发酵罐顶空一般取接种麦汁体积的 18–25%（小麦啤酒约 40%）；液高最好不超过约 20 m，直径与总液高约 1 : 2。CIP 按每米罐周长约 30 hl/h 估算。

| 输入 | 示例值 |
| --- | --- |
| 罐直径 | 4.5 m |
| 锥角 | 70 ° |
| 总液高（含锥部） | 12 m |
| 顶空比例 | 25 % |

| 结果 | 示例输出 |
| --- | --- |
| 锥高 | 3.21 m |
| 麦汁容量 | 1,568 hl |
| 顶空高度 | 2.46 m |
| 筒体+锥部总高（不含封头） | 14.46 m |
| 直径 : 总液高 | 1 : 2.7 |
| CIP 清洗液（约） | 11.8 L/s |

## 发酵与冷贮冷量

*Kunze p.395、429* · 用于 [4.5 锥形罐发酵与成熟](04-fermentation.md#s4-5)

发酵热按每 kg 已发酵浸出物 587 kJ；已发酵浸出物 ≈ 原麦汁 × 0.81 × 表观发酵度。全麦啤酒发酵热约 4,300–4,600 kJ/hl，从 9 °C 冷到 −1 °C 约 4,200 kJ/hl，加上散热损失总计约 8,600–9,000 kJ/hl；最大冷量出现在发酵后 24–48 h 的降温。

| 输入 | 示例值 |
| --- | --- |
| 原麦汁 | 12 °P |
| 最终表观发酵度 | 80 % |
| 发酵后降温幅度 | 10 K |
| 批量 | 1000 hl |

| 结果 | 示例输出 |
| --- | --- |
| 发酵热 | 4,565 kJ/hl |
| 降温液体热 | 4,200 kJ/hl |
| 合计（未含散热） | 8,765 kJ/hl |
| 整批 | 8,765 MJ |

## 巴氏杀菌单位 PU

*Kunze p.489–490* · 用于 [5.3 生物稳定化](05-filtration-stabilisation.md#s5-3)

1 PU = 60 °C 保持 1 min；PU = 时间(min) × 1.393^(T−60)。啤酒一般 14–15 PU，污染重时 22–27 PU；罐装啤酒 18–20 PU，温度不超过约 62 °C。PU 衡量杀菌效果，不衡量风味损伤——后者更取决于保持时间和含氧量。

| 输入 | 示例值 |
| --- | --- |
| 杀菌温度 | 70 °C |
| 保持时间 | 50 s |
| 目标 | 15 PU |

| 结果 | 示例输出 |
| --- | --- |
| 得到 | 22.9 PU |
| 达到目标需保持 | 33 s |
| 温度倍率 | 27.51 × /min |

> 达到 15 PU 所需时间：62 °C 464 s · 64 °C 239 s · 66 °C 123 s · 68 °C 63 s · 70 °C 33 s · 72 °C 17 s

## 啤酒损耗与麦芽单耗

*Kunze p.709–712* · 用于 [6.7 损耗、麦芽单耗与产能](06-filling-cleaning.md#s6-7)

| 投料量 | 180000 kg |

| 结果 | 示例输出 |
| --- | --- |
| 啤酒损耗 | 10.26 % |
| 损失体积 | 1,200 hl |
| 麦芽单耗 | 17.14 kg/hl |

## 原麦汁与发酵度（Balling 公式）

*Kunze p.767–768* · 用于 [7.8 理化分析](07-finished-beer.md#s7-8)

Balling 公式：原麦汁 =（2.0665 × 酒精质量分数 + 真正浸出物）× 100 ÷（100 + 1.0665 × 酒精质量分数）；平均 2.0665 g 浸出物生成 1 g 酒精、0.9565 g CO₂ 和 0.11 g 酵母。体积分数按“酒精质量分数 = 体积分数 × 0.7893 ÷ 啤酒密度”换算，啤酒密度由表观浸出物求得。示例是书中 VLB 2002 年 375 个比尔森的平均值，算出的原麦汁与书中一致。不适用于去醇啤酒和含酵母的上面发酵啤酒。

| 输入 | 示例值 |
| --- | --- |
| 酒精（体积分数） | 5.07 % vol |
| 表观浸出物 | 2.04 % |
| 真正浸出物 | 3.84 % |

| 结果 | 示例输出 |
| --- | --- |
| 酒精（质量分数） | 3.98 mas% |
| 原麦汁浓度 | 11.57 % |
| 表观发酵度 | 82.4 % |
| 真正发酵度 | 66.8 % |
| 真正 ÷ 表观 | 0.81 |

## 废水与副产物估算

*Kunze p.799–809* · 用于 [9.1 废水：来源、指标与费用](09-environment.md#s9-1)

除进入啤酒、副产物和蒸发掉的约 1.8–2.5 hl/hl 外，用水全部变成废水（书中：用水 6 hl/hl 时废水 3.5–4.2 hl/hl）；目标是废水不超过 4.0 hl/hl、COD 不超过 600 g/hl。酒厂废水 BOD₅ 约 1200 mg/L；1 个人口当量按每天 60 g BOD₅ 计。副产物按书中经验值：湿酒糟约 20 kg/hl，剩余酵母每 1 万 hl 每年 15–18 t，废硅藻土约 0.5 kg/hl 过滤啤酒。

| 输入 | 示例值 |
| --- | --- |
| 年销售啤酒 | 100000 hl |
| 用水 | 5 hl/hl |
| 进入产品、副产物和蒸发的水 | 2 hl/hl |
| 废水 BOD₅ | 1200 mg/L |

| 结果 | 示例输出 |
| --- | --- |
| 废水量 | 3.0 hl/hl |
| 年废水量 | 30,000 m³ |
| 年 BOD₅ 负荷 | 36.0 t |
| 约合人口当量 | 1,644 人 |
| 湿酒糟 | 2,000 t/年 |
| 剩余酵母 | 150–180 t/年 |
| 废硅藻土（全部过滤时） | 50 t/年 |

## 有效热价与年燃料费

*Kunze p.812–814* · 用于 [10.1 能耗基准与热价](10-energy.md#s10-1)

热价 = 燃料价格 ÷ 热值；有效热价 = 热价 ÷ 锅炉效率，才是生产用 1 MJ 热的真实成本。书中的低位热值：天然气 H 37,500 kJ/m³、L 31,950 kJ/m³，轻质燃料油 42,700 kJ/kg（按 kg 计价时把单位换成 EUR/kg、kJ/kg 即可）。标称效率指最佳工况，平均效率很少超过 85%；全厂热耗约 180–200 MJ/hl。燃料价格是示例值，不是书中数据，请换成自己的。

| 输入 | 示例值 |
| --- | --- |
| 燃料价格（示例） | 0.4 EUR/m³ |
| 低位热值 | 37500 kJ/m³ |
| 锅炉平均效率 | 85 % |
| 全厂热耗 | 190 MJ/hl |
| 年销售啤酒 | 100000 hl |

| 结果 | 示例输出 |
| --- | --- |
| 热价 | 1.07 欧分/MJ |
| 有效热价 | 1.25 欧分/MJ |
| 合每 kWh 热 | 4.52 欧分 |
| 年耗热 | 19,000 GJ |
| 年燃料费 | 238,431 EUR |

## 制冷：蒸发与冷凝温度的节电效果

*Kunze p.826–827、842* · 用于 [10.3 制冷](10-energy.md#s10-3)

经验规则：冷凝温度每降 1 K，压缩机驱动功率约降 2–2.5%；蒸发温度每升 1 K，约降 3–3.5%（p.842 取 2.5% 和 3%）。办法：按用户需要的蒸发温度分开回路、直接蒸发、保持冷凝器清洁并排除不凝气、把液氨过冷。这里按线性叠加估算，只适用于几 K 的变化；电价 0.09 EUR/kWh 取自书中当时的 0.08–0.10 EUR/kWh。

| 输入 | 示例值 |
| --- | --- |
| 制冷压缩机年耗电 | 1000000 kWh |
| 蒸发温度提高 | 2 K |
| 冷凝温度降低 | 3 K |
| 电价 | 0.09 EUR/kWh |

| 结果 | 示例输出 |
| --- | --- |
| 节电比例 | 12.0–14.5 % |
| 年节电 | 120,000–145,000 kWh |
| 年节省 | 10,800–13,050 EUR |

> 另外：用直接蒸发代替载冷剂（间接冷却），约可再省 9–12% 的电。

## 功率因数与需量电费

*Kunze p.843–848* · 用于 [10.4 电能与功率因数](10-energy.md#s10-4)

三相有功功率 = √3 × 线电压 × 电流 × cos φ；同样的有功功率，cos φ 越低，电流和视在功率越大，电缆要更粗、损耗更大。书中例子（单相 220 V、10 kW）：cos φ = 0.8 需 57 A，0.4 需 114 A。需量电价按 15 min 最大负荷（kVA）计，书中当时约 50–180 EUR/kW·年，所以要用电容补偿、把制冷等大负荷挪到夜间，并用负荷控制自动甩负荷。示例的需量电价取书中范围内的 100。

| 输入 | 示例值 |
| --- | --- |
| 有功功率峰值（15 min） | 500 kW |
| 当前 cos φ | 0.75 |
| 补偿后 cos φ | 0.9 |
| 线电压（三相） | 380 V |
| 需量电价 | 100 EUR/kVA·年 |

| 结果 | 示例输出 |
| --- | --- |
| 当前视在功率 | 667 kVA |
| 补偿后视在功率 | 556 kVA |
| 线电流（当前 → 补偿后） | 1,013 → 844 A |
| 每年需量电费可省 | 11,111 EUR |

## 管道流速与管径

*Kunze p.902–905* · 用于 [11.4 管道设计](11-automation-planning.md#s11-4)

流速 = 流量 ÷ 管截面积。推荐流速上限：麦汁与啤酒 ≤3.0 m/s，去过滤槽的醪 ≤1.5，浓酵母 ≤1.0，泵吸入管冷介质 ≤1.8、热介质 ≤1.0，水 ≤4.0（长管 ≤2.0），液氨 ≤1.6，压缩空气和 CO₂ 10–25 m/s。书中例：40 m³/h 的水走 60 m DN 50 管约 5.7 m/s、压降约 4.7 bar，换 DN 65 约 3.4 m/s、约 1.3 bar（压降按书中列线图查得，这里不计算）。含 CO₂ 的介质，沿程压力不能低于 CO₂ 平衡压力的 1.5 倍。

| 输入 | 示例值 |
| --- | --- |
| 流量 | 40 m³/h |
| 管内径（约等于 DN） | 50 mm |
| 允许流速 | 3 m/s |

| 结果 | 示例输出 |
| --- | --- |
| 流速 | 5.66 m/s |
| 截面积 | 19.6 cm² |
| 满足允许流速的最小管径 | DN 80 |

> 提示：流速超过允许值：压降和剪切都会增大。
