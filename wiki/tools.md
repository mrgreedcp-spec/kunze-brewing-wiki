## 煮出醪量

*Kunze p.244–245* · 用于 [3.2 糖化](03-wort-production.md#s3-2)

煮出醪量 = 升温幅度 × 总醪量 ÷（90 °C − 未煮醪温度）。90 °C 是煮沸醪泵回时考虑降温后的有效温度；经验值约为总醪的 1/4–1/3。书中 p.245 示例的算术有排印错误，按公式应为 45.5 hl。

| 输入 | 示例值 |
| --- | --- |
| 总醪量 | 120 hl |
| 未煮醪（休止）温度 | 50 °C |
| 回混后目标温度 | 64 °C |
| 煮沸醪回混时的有效温度 | 90 °C |

| 结果 | 示例输出 |
| --- | --- |
| 需煮沸的稠醪 | 42.0 hl |
| 占总醪 | 35 % |
| 留在锅里不煮 | 78.0 hl |

## 投料水与头道麦汁浓度

*Kunze p.234–235* · 用于 [3.2 糖化](03-wort-production.md#s3-2)

经验法则：100 kg 粉 + 3 hl 水 ≈ 20% 头道麦汁，水量与目标浓度成反比；粉的体积按约 0.7 hl/100 kg 计。头道麦汁一般比成品原麦汁高 4–6%，淡色啤酒常用 3–4 hl/100 kg。

| 输入 | 示例值 |
| --- | --- |
| 投料（粉） | 3000 kg |
| 目标头道麦汁浓度 | 18 % |

| 结果 | 示例输出 |
| --- | --- |
| 投料水 | 100.0 hl |
| 醪体积约 | 121.0 hl |
| 料水比 | 3.3 L/kg |

## 酒花添加量

*Kunze p.320–321* · 用于 [3.5 麦汁煮沸与加酒花](03-wort-production.md#s3-5)

BU = 每升啤酒中苦味物的毫克数；按冷麦汁体积（热体积 × 0.96）计算。苦味收率一般 25–35%，要在自己的厂里试验确定：需加入的 α-酸克数大约是目标 BU 值的 1/3（每 hl）。苦型酒花先加，香型酒花后加。

| 输入 | 示例值 |
| --- | --- |
| 目标苦味 | 30 BU |
| 热定型麦汁 | 200 hl |
| 苦味收率（按成品） | 30 % |
| 产品 A 承担的比例 | 70 % |
| 产品 A 的 α-酸 | 12 % |
| 产品 B 的 α-酸 | 5 % |

| 结果 | 示例输出 |
| --- | --- |
| 冷定型麦汁 | 192.0 hl |
| 进入啤酒的苦味物 | 576 g |
| 需加入的 α-酸 | 1.92 kg |
| 产品 A | 11.2 kg |
| 产品 B | 11.5 kg |

## 糖化间收率与发酵间收率

*Kunze p.323–331、398–399* · 用于 [3.6 糖化间收率](03-wort-production.md#s3-6)

收率 = 浸出物(kg/hl) × 0.96 × 热定型量 ÷ 投料。kg/hl 由 °P 乘以 20/4 °C 比重得到，即书中 Plato 表的“g/100 mL”一栏；0.96 是热麦汁冷到 20 °C 的收缩系数。接种麦汁是冷的，不再乘 0.96。正常糖化间收率 74–79%。

| 输入 | 示例值 |
| --- | --- |
| 投料 | 4000 kg |
| 热定型麦汁 | 262 hl |
| 定型麦汁浓度 | 11.6 °P |
| 接种麦汁（冷） | 254 hl |
| 接种麦汁浓度 | 11.4 °P |

| 结果 | 示例输出 |
| --- | --- |
| 浸出物（20 °C） | 12.12 kg/hl |
| 收率因子 | 11.64 |
| 糖化间浸出物 | 3,048 kg |
| 糖化间收率 | 76.21 % |
| 发酵间收率 | 75.57 % |
| 定型→接种损失 | 25 kg 浸出物 |

## 表观与真实发酵度

*Kunze p.403–406* · 用于 [4.4 常规发酵与贮酒](04-fermentation.md#s4-4)

转罐时一般希望与极限相差约 10 个百分点（约 1% 浸出物），留给贮酒罐里的后发酵产生 CO₂；灌装前的最终发酵度则应尽量接近极限，否则等于给微生物留了糖。真实发酵度 ≈ 0.81 × 表观发酵度（Balling 经验系数）。

| 输入 | 示例值 |
| --- | --- |
| 原麦汁（接种麦汁） | 12 °P |
| 当前表观浸出物 | 3.8 °P |
| 发酵度极限对应的浸出物 | 2.1 °P |

| 结果 | 示例输出 |
| --- | --- |
| 表观发酵度 Vs | 68.3 % |
| 真实发酵度 ≈ | 55.4 % |
| 发酵度极限 | 82.5 % |
| 与极限相差 | 14.2 个百分点 |
| 残余可发酵浸出物 | 1.7 °P |

## 调配（混合十字）

*Kunze p.408–409* · 用于 [4.4 常规发酵与贮酒](04-fermentation.md#s4-4)

混合十字：把两种液体的浸出物写在左侧、目标写在中间，交叉相减得到两者的份数；混合方程 V1·E1 + V2·E2 =（V1+V2）·Et 给出同样结果。按百分数计算是近似，严格计算应换成 20/4 °C 密度；而且两种液体很难真正混匀。

| 输入 | 示例值 |
| --- | --- |
| 啤酒（麦汁）A 的量 | 500 hl |
| A 的浸出物 | 12.4 % |
| B 的浸出物（水填 0） | 0 % |
| 目标浸出物 | 11.6 % |

| 结果 | 示例输出 |
| --- | --- |
| 需加入 B | 34.5 hl |
| 调配后总量 | 534.5 hl |
| A : B | 11.6 : 0.8 |

## CO₂ 溶解量

*Kunze p.409–410* · 用于 [4.4 常规发酵与贮酒](04-fermentation.md#s4-4)

亨利定律：溶解量 ≈ 该温度下常压溶解度 × 绝对压力（按书中做法，常压取 1 bar）。常压溶解度取书中 12 °P、发酵度 80% 啤酒的数值并线性插值，0 °C 以下为外推。灌装的啤酒应含约 0.5% CO₂。

| 输入 | 示例值 |
| --- | --- |
| 啤酒温度 | 1 °C |
| 罐压（表压） | 0.5 bar |
| 目标 CO₂ 含量 | 0.5 % |

| 结果 | 示例输出 |
| --- | --- |
| 饱和 CO₂ 含量 | 0.459 % |
| 约合 | 4.6 g/L |
| 该温度常压溶解度 | 0.306 % |
| 达到目标所需表压 | 0.63 bar |

> 提示：低于 0.50%：灌装途中还会损失一些，贮酒时宜再高一点。

## 接种量

*Kunze p.400、438* · 用于 [4.4 常规发酵与贮酒](04-fermentation.md#s4-4)

常用接种量 20–30×10⁶ 个/mL，约相当于每 hl 0.6–1 L 浓酵母泥（泥约 3×10⁹ 个/mL）。提高接种量是加快发酵而不带来负面后果的最重要手段，也能减少高级醇。

| 输入 | 示例值 |
| --- | --- |
| 目标细胞浓度 | 25 ×10⁶/mL |
| 酵母泥浓度 | 3 ×10⁹/mL |
| 麦汁量 | 500 hl |

| 结果 | 示例输出 |
| --- | --- |
| 每 hl 酵母泥 | 0.83 L |
| 总共需要 | 417 L |

## 锥形罐容积与顶空

*Kunze p.417–419、426* · 用于 [4.5 锥形罐发酵与成熟](04-fermentation.md#s4-5)

锥部 V = πr²h/3，筒体 V = πr²h；锥角 60° 时锥高 ≈ 0.866 × 直径。发酵罐顶空一般取接种麦汁体积的 18–25%（小麦啤酒约 40%）；液高最好不超过约 20 m，直径与总液高约 1 : 2。CIP 按每米罐周长约 30 hl/h 估算。

| 输入 | 示例值 |
| --- | --- |
| 罐直径 | 4.5 m |
| 锥角 | 70 ° |
| 总液高（含锥部） | 12 m |
| 顶空比例 | 25 % |

| 结果 | 示例输出 |
| --- | --- |
| 锥高 | 3.21 m |
| 麦汁容量 | 1,568 hl |
| 顶空高度 | 2.46 m |
| 筒体+锥部总高（不含封头） | 14.46 m |
| 直径 : 总液高 | 1 : 2.7 |
| CIP 清洗液（约） | 11.8 L/s |

## 发酵与冷贮冷量

*Kunze p.395、429* · 用于 [4.5 锥形罐发酵与成熟](04-fermentation.md#s4-5)

发酵热按每 kg 已发酵浸出物 587 kJ；已发酵浸出物 ≈ 原麦汁 × 0.81 × 表观发酵度。全麦啤酒发酵热约 4,300–4,600 kJ/hl，从 9 °C 冷到 −1 °C 约 4,200 kJ/hl，加上散热损失总计约 8,600–9,000 kJ/hl；最大冷量出现在发酵后 24–48 h 的降温。

| 输入 | 示例值 |
| --- | --- |
| 原麦汁 | 12 °P |
| 最终表观发酵度 | 80 % |
| 发酵后降温幅度 | 10 K |
| 批量 | 1000 hl |

| 结果 | 示例输出 |
| --- | --- |
| 发酵热 | 4,565 kJ/hl |
| 降温液体热 | 4,200 kJ/hl |
| 合计（未含散热） | 8,765 kJ/hl |
| 整批 | 8,765 MJ |

## 巴氏杀菌单位 PU

*Kunze p.489–490* · 用于 [5.3 生物稳定化](05-filtration-stabilisation.md#s5-3)

1 PU = 60 °C 保持 1 min；PU = 时间(min) × 1.393^(T−60)。啤酒一般 14–15 PU，污染重时 22–27 PU；罐装啤酒 18–20 PU，温度不超过约 62 °C。PU 衡量杀菌效果，不衡量风味损伤——后者更取决于保持时间和含氧量。

| 输入 | 示例值 |
| --- | --- |
| 杀菌温度 | 70 °C |
| 保持时间 | 50 s |
| 目标 | 15 PU |

| 结果 | 示例输出 |
| --- | --- |
| 得到 | 22.9 PU |
| 达到目标需保持 | 33 s |
| 温度倍率 | 27.51 × /min |

> 达到 15 PU 所需时间：62 °C 464 s · 64 °C 239 s · 66 °C 123 s · 68 °C 63 s · 70 °C 33 s · 72 °C 17 s

## 高浓酿造节能

*Kunze p.510* · 用于 [5.6 特殊工艺](05-filtration-stabilisation.md#s5-6)

按书中的简化算法（体积 × 百分浓度）。高浓的主要好处是稀释水不必加热和煮沸；代价是发酵更慢、酯和高级醇更多，泡沫也随稀释程度变差。

| 输入 | 示例值 |
| --- | --- |
| 常规定型量 | 300 hl |
| 常规浓度 | 11 % |
| 高浓浓度 | 15 % |

| 结果 | 示例输出 |
| --- | --- |
| 高浓定型量 | 220.0 hl |
| 少加热煮沸 | 80.0 hl |
| 节省比例 | 26.7 % |
| 后续稀释水 | 80.0 hl |

## 啤酒损耗与麦芽单耗

*Kunze p.709–712* · 用于 [6.4 损耗、麦芽单耗与产能](06-filling-cleaning.md#s6-4)

损耗 = 定型麦汁与可售啤酒之差占定型麦汁的百分比，平均 8–10%（其中约 4% 是冷缩）。麦芽单耗参考：6% 啤酒约 9 kg/hl，11% 约 17 kg/hl，16% 约 26 kg/hl。收率与损耗的百分数不能相加。

| 输入 | 示例值 |
| --- | --- |
| 定型麦汁量 | 11700 hl |
| 可售啤酒量 | 10500 hl |
| 投料量 | 180000 kg |

| 结果 | 示例输出 |
| --- | --- |
| 啤酒损耗 | 10.26 % |
| 损失体积 | 1,200 hl |
| 麦芽单耗 | 17.14 kg/hl |

## 糖化间年产能

*Kunze p.333–334* · 用于 [6.4 损耗、麦芽单耗与产能](06-filling-cleaning.md#s6-4)

书中经验：1 hl 啤酒约耗 17 kg 麦芽；1 t 投料约定型 64.6 hl 麦汁；每天 8 批、每周 5 天时，每 1 t 投料能力大约对应每年 10 万 hl 啤酒。这是理论上限，维修停产会明显降低。

| 输入 | 示例值 |
| --- | --- |
| 每批定型麦汁 | 640 hl |
| 每天批次 | 8 批 |
| 每周酿造天数 | 5 天 |
| 每年生产周 | 52 周 |
| 节假日 | 10 天 |
| 损耗 | 9 % |

| 结果 | 示例输出 |
| --- | --- |
| 每天定型麦汁 | 5,120 hl |
| 每年定型麦汁 | 1,280,000 hl |
| 每年可售啤酒 | 1,164,800 hl |
