# 02 制麦（Malt production）

> Kunze 原书印刷页 p.97–194 · [返回首页](README.md)

让大麦在受控条件下发芽，产生酶并“溶解”胚乳，再用热终止生命活动、定型色香、赶走 DMS。细胞溶解只有麦芽厂能做好，酒厂事后只能部分弥补。

- **输入**：清选后的酿造大麦（水分 12–14%）
- **输出**：麦芽（水分 &lt;5%）；100 kg 大麦约得 80 kg
- **关键数字**：浸麦度 42–48% · 发芽 5 d ≤18 °C · 焙焦 80–85 °C

**本页工序**：[2.1 接收、清选与分级](#s2-1) · [2.2 干燥与贮存](#s2-2) · [2.3 浸麦](#s2-3) · [2.4 发芽](#s2-4) · [2.5 焙焦](#s2-5) · [2.6 焙焦后处理与制麦收率](#s2-6) · [2.7 麦芽评价](#s2-7) · [2.8 特种麦芽](#s2-8)

## 2.1 接收、清选与分级（Intake, cleaning, grading）

*Kunze p.98–120*

**目的**：只让干净、同品种、粒度均匀的大麦进入浸麦；同时把火花和粉尘爆炸的风险降到最低。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 清选顺序 | 预清（振动筛 + 吸风）→ 磁选 → 去石 → 精选（窝眼滚筒，大麦用 6.5 mm 窝眼）→ 分级 → 计量 |
| 分级筛 | 留在 2.5 mm 上为 I 级；2.2–2.5 mm 为 II 级；&lt;2.2 mm 作饲料 |
| 气力输送 | 悬浮需 ≥11 m/s，输送约 20 m/s |
| 斗式提升 | 大麦 ≤4 m/s，麦芽 ≤2.5 m/s |

**机理与要点**

- 大小粒吸水速度不同，分级是为了浸麦均匀；如今很多厂把 &gt;2.2 mm 的大麦一起制麦，更看重品种纯度。
- 铁件和石子会损伤设备并打出火花，而粮食粉尘在一定浓度下能爆炸 → 磁选、去石、除尘（旋风预分离 + 布袋或脉冲滤筒）缺一不可。

**自测**

<details><summary>为什么粉碎机和提升机之前都要磁选？</summary>

铁件撞击会产生火花，可能点燃粉尘；它还会打坏辊子的齿纹。

</details>

## 2.2 干燥与贮存（Drying and storage）

*Kunze p.120–126*

**目的**：让大麦安全度过休眠期，保住发芽力，把呼吸损失和霉变降到最低。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 休眠期 | 收获后约 6–8 周才达到“制麦成熟度” |
| 安全贮存 | 水分 12–15% 且 9–12 °C 可长期保存；16.6–18% 须降到 5–7 °C，只能存 4–6 个月 |
| 呼吸强度（20 °C） | 水分 14–15% 约 1.4 mg CO₂/(kg·天)，17% 约 100，20.5% 约 359 |
| 平仓堆高 | 水分 ≤15.5% 可堆 3 m；&gt;17% 只能堆 1 m |
| 贮存损失 | 筒仓约 0.5%（3 个月内）到 2%（6 个月以上） |

**机理与要点**

- 呼吸消耗淀粉，就是浸出物损失；水分和温度同时升高时呼吸会连锁放大，进而发热霉变。
- 冷却（向仓底送冷风）能推迟干燥，并抑制米象（12–15 °C 以下活动很弱）。
- 田间镰刀菌产生 DON、ZEA 等霉菌毒素，也与喷涌有关。

**自测**

<details><summary>为什么湿大麦必须先干燥再入仓？</summary>

水分超过约 15% 时呼吸急剧增强，发热、耗淀粉、滋生霉菌，最后还会丧失发芽力。

</details>

## 2.3 浸麦（Steeping）

*Kunze p.126–135*

**目的**：给籽粒补水、供氧、清洗，让胚苏醒并开始产酶。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 浸麦度（目标水分） | 淡色 42–44%（分步提水可到 48%）；深色 44–47% |
| 吸水到 42% 所需时间 | 5 °C 约 100 h，10 °C 约 75 h，15 °C 约 50 h |
| 典型节奏 | 湿浸 4 h → 空气休止约 20 h（每小时抽 CO₂ 10–15 min）→ 第二次湿浸 → 出槽后在发芽箱喷水补足 |
| 空气休止占比 | 约 80% 的浸麦时间 |
| 用水 | 4–7 m³/t（回用可到约 3.5）；仅把水分从 12% 提到 45% 就要 0.94 m³/t |
| 体积膨胀 | 约 40–45% |

**机理与要点**

- 吸水后呼吸大增。泡在水里缺氧会转入分子内呼吸、生成醇和醛，严重时胚被“浸死”。CO₂ 比空气重，要从槽底抽走。
- 小粒吸水快，所以分级后分别浸麦更均匀；对水敏感的大麦，先在 37–40% 水分等它破口，再逐步加水。
- 第一遍浸麦水很脏（单宁、苦味物、硅酸、谷皮蛋白），必须换掉。
- 浸麦槽里一般只到 36–38%，其余水分在发芽设备中喷水完成——浸麦和发芽其实是连续的。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 发芽不齐 | 分级不严；锥底积聚 CO₂；通风不足 | 底部抽 CO₂、用压缩空气翻动；平底槽均匀装料 |

**自测**

<details><summary>为什么现代浸麦把大部分时间都安排成空气休止？</summary>

胚在吸水后需要大量氧来呼吸和产酶；长时间泡水缺氧，发芽慢且不均，甚至死胚。

</details>

<a id="s2-4"></a>

## 2.4 发芽（Germination）

*Kunze p.135–158*

**目的**：让酶大量形成，把胚乳细胞壁和蛋白基质分解开（溶解），同时把呼吸和根芽造成的损失压到最低。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 发芽时间 | 现多为 5 天（5–6 天） |
| 最高温度 | 比尔森麦芽 17–18 °C；深色麦芽 22–25 °C |
| 绿麦芽水分 | 约 45%（不低于 40%） |
| 料层 | 装料 1.2–1.3 m，发芽后长到 1.8–1.9 m |
| 通风 | 300–700 m³/(t·h)，进风比料层低约 2 °C，并保持饱和湿度 |
| 叶芽长度 | 淡色 2/3–3/4 粒长；深色 3/4–1；超过粒长称“骠骑兵” |
| 根芽 | 淡色约 1.5 倍粒长，深色约 2 倍 |
| 第 3 天起 | 先减半新风，之后掺入 80% 以上富 CO₂ 的循环风限制呼吸 |

**机理与要点**

- 胚分泌赤霉酸 → 糊粉层新合成 α-淀粉酶（大麦中原本没有）、界限糊精酶、葡聚糖酶和蛋白酶；β-淀粉酶原本就在胚乳里，只是被释放出来。多数酶在第 3–4 天形成。
- 溶解顺序固定：先分解细胞壁中层的蛋白，再是戊聚糖，最后才轮到 β-葡聚糖骨架；溶解从盾片向粒尖推进。粒尖没溶解，就会把淀粉和 β-葡聚糖问题带进糖化间。
- 蛋白溶解（库尔巴哈指数）与细胞溶解同步进行。太高会让焙焦时美拉德反应过强，TBI 和色度上升、风味稳定性下降。
- 冷发芽总能得到最高的淀粉酶量；发芽越暖越久，根越长、损失越大。
- 发芽中形成 DMS 前体（SMM）：浸麦度越高、发芽温度越高、时间越长，前体越多。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 溶解过度 | 浸麦度高、温度高、时间长 | 限制绿麦芽水分、降温，第 3 天起减氧 |
| 溶解不足或不均 | 起发不齐、水分不够 | 保证均匀起发和足够水分；检查品种纯度 |

**自测**

<details><summary>为什么说“细胞溶解只能交给麦芽厂”？</summary>

分解 β-葡聚糖的内切葡聚糖酶很怕热，糖化中很快失活；而耐热的 β-葡聚糖溶解酶会把未溶解部位的大分子 β-葡聚糖释放出来却不分解它，酒厂没法根本补救。

</details>

<details><summary>叶芽长度为什么能用来判断溶解？</summary>

叶芽在谷皮下沿背部向粒尖生长，长度大致与溶解进度同步；超过粒长说明温度太高或发芽过度。

</details>

## 2.5 焙焦（Kilning）

*Kunze p.158–172*

**目的**：把水分从 40% 以上降到 5% 以下、终止生命活动，尽量保留酶，按啤酒类型生成或避免色香物质，并把 DMS 前体赶走。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 两段 | 凋萎（预干）+ 焙焦；水分降到 10–12% 之前，料温不超过约 50 °C |
| 淡色（比尔森） | 80–85 °C 保持 3–5 h；宁取 85 °C 2–3 h，不取 80 °C 5 h |
| 深色（慕尼黑） | 100–105 °C |
| 风量 | 约 4,300–5,000 m³/(t·h)，穿透点后可降到约一半 |
| 淡色麦芽的酶保留 | α-淀粉酶比绿麦芽约高 15%；β-淀粉酶约低 40%；内切 β-葡聚糖酶损失 20–40% |
| 风味稳定指标 | 麦芽 TBA &lt;14；DMS 前体 &lt;5–6 ppm；亚硝胺（NDMA）限值约 2.5 µg/kg |
| 热耗（带热回收） | 单层炉 250–300 MJ/t，双层炉 200–250 MJ/t；热回收可省 30–35% |

**机理与要点**

- 湿热会破坏酶，湿淀粉在高温下糊化后冷却成玻璃质 → 必须先低温大风量除水，干了再升温。
- 美拉德反应与 Strecker 降解在 90 °C 以上、时间较长时明显：生成类黑精（颜色、香气、还原力），也生成日后老化味的前体。热负荷用 TBA（TBI）表示。
- SMM → DMS 活性前体 → 游离 DMS：温度越高，转化并排出越多；但温度越高、时间越长，TBA 也越高。高温短时是两者的折中。
- 淡色麦芽前半段强风快速干燥，让酶来不及分解；深色麦芽关风门在湿热中“焖”，让酶生成大量糖和氨基酸，供焙焦时显色生香。
- 改用间接加热后，燃气中的 NOx 不再穿过麦芽，亚硝胺问题基本解决；烟熏麦芽则是有意让山毛榉烟穿过麦芽。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 玻璃质麦芽 | 水分还高时就升温 | 严格控制穿透点之前的料温 |
| DMS 前体偏高 | 焙焦温度不足或保持太短 | 提高焙焦温度或延长保持时间 |

**自测**

<details><summary>为什么比尔森麦芽宁要 85 °C 2–3 h，而不要 80 °C 5 h？</summary>

两种方式都能把 DMS 前体降到目标，但高温短时的累计热负荷（TBA）更低，对风味稳定性更有利。

</details>

## 2.6 焙焦后处理与制麦收率（After kilning, malting yield）

*Kunze p.172–174*

**目的**：冷却、除根、贮存熟化和抛光，并核算制麦损失。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 出炉 | 约 80 °C，冷却到 35–40 °C 以下 |
| 麦根 | 约占麦芽 3–4%，蛋白约 30%，是优质饲料 |
| 贮存 | 至少 4 周：水分回升到 4–5%，加工性能改善 |
| 干物质损失 | 淡色 10.5%（浸麦 1.0 + 呼吸 5.8 + 麦根 3.7）；深色 13.0% |
| 经验收率 | 100 kg 大麦约得 80 kg 淡色麦芽 |

**机理与要点**

- 新焙焦的麦芽直接用会造成过滤和发酵困难，所以要贮存熟化。
- 麦芽吸湿，库房要干燥凉爽；筒仓表面积小，吸湿风险低。
- 降低损失的办法：低温发芽，从第 3 天起多用富 CO₂ 循环风限制呼吸和根的生长。

**相关工具**：[数据：制麦物料质量变化](programmes.md#malting)

**自测**

<details><summary>100 kg 大麦只出 80 kg 麦芽，20 kg 去哪了？</summary>

大约一半是水分差（大麦 12–14% 对麦芽 3–4%），另一半是干物质损失：呼吸消耗最多，其次是被除去的麦根，少量随浸麦水流失。

</details>

## 2.7 麦芽评价（Malt evaluation）

*Kunze p.174–179*

**目的**：用一组指标判断这批麦芽能不能在酒厂里顺利糖化、过滤和发酵。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 水分 | 淡色 3.0–4.5%；合同上限 5% |
| 浸出率（细粉，干基） | 淡色约 80–82% 以上；深色 75–78% |
| 粗细粉差 | 1.2–1.8%（&lt;1.8% 为好） |
| 库尔巴哈指数 | 38–42%（&lt;35 溶解不足，&gt;41 过度） |
| 脆度 | &gt;85–87%；全玻璃质粒 &lt;2% |
| 协定麦汁黏度 | &lt;1.55–1.6 mPa·s（8.6% 浓度） |
| β-葡聚糖（65 °C 协定麦汁） | &lt;350 mg/L |
| 色度 | 淡色协定麦汁 ≤4 EBC；煮沸麦汁 ≤5–7 EBC |
| 糖化力 | 淡色 240–260 WK |
| 游离氨基氮 | 120–160 mg/100 g 干麦芽 |
| DMS 前体 / TBA | ≤5 mg/kg；TBA ≤14–15 |

**机理与要点**

- 协定糖化法是各项分析的共同基础：50 g 麦芽粉加 200 mL 水，45–46 °C 保持 30 min，以 1 °C/min 升到 70 °C，再加 100 mL 水保持 1 h，冷却补重后过滤测浸出物。
- Carlberg 纵切染色法看均一性（≥70%，最好 75%），能发现混入的短芽麦芽。
- 近红外快速仪器能在 1 分钟内给出主要数据。

**自测**

<details><summary>为什么同时需要“脆度”和“库尔巴哈指数”两个溶解指标？</summary>

脆度看细胞壁（物理上是否松脆，关系 β-葡聚糖和过滤）；库尔巴哈看蛋白溶解（可溶氮占总氮，关系泡沫、FAN 和色度）。两者可以不同步。

</details>

## 2.8 特种麦芽（Special malts）

*Kunze p.179–187*

**目的**：用不同的发芽、焖热和焙焦或焙炒路线，得到颜色、香气和酒体各不相同的麦芽。

| 麦芽 | 色度 EBC | 工艺要点 | 常见用法 |
| --- | --- | --- | --- |
| 比尔森（淡色） | 2.5–3.5 | 有限溶解；80–85 °C 焙焦 | 淡色啤酒的基础麦芽 |
| 维也纳 | 6–8 | 浸麦度 44–46%；90–95 °C 焙焦 | 可全部用于三月、节日啤酒 |
| 慕尼黑（深色） | 15–25 | 高蛋白大麦、强化发芽、湿热凋萎；100–105 °C 焙焦 4–5 h | 深色啤酒的基础；25–40% 用于增香 |
| 类黑精麦芽 | 50–80 | 发芽末期 40–50 °C 焖热；90–100 °C 以上焙焦 | 5–20%，带来红色调和酒体 |
| 浅焦香（Carahell 类） | 20–40 | 焙炒滚筒里 70–80 °C 让籽粒内部糖化，再焙炒 | 提升酒体和泡沫 |
| 深焦香（Caramünch 类） | 80–160 | 焙炒升到 180–210 °C | 深色节日啤酒、琥珀色啤酒 |
| 糊精麦芽（Carapils 类） | 3.5–5 | 只糖化，60–65 °C 低温烘干 | 至 15%；无醇啤酒可到 30% |
| 酸麦芽 | 约 3.5 | 绿麦芽喷乳酸，含 2–4% 乳酸，pH 3.4–3.5 | 降低醪 pH；配硬水常用 6–9% |
| 焙烤、巧克力麦芽 | 800–1,600 | 淡色麦芽润湿后 180–220 °C 焙烤，喷水“去苦” | 0.5–2% 调色 |
| 小麦麦芽 | 3–4（深色 15–17） | 无皮、吸水快、易结块要勤翻；限制蛋白分解 | 小麦啤酒 50–70% |

**机理与要点**

- 焦香麦芽的“糖化”发生在滚筒里的籽粒内部，生成的糖随即焦糖化，所以带来焦糖香和酒体；焙烤麦芽则是用干的淡色麦芽直接高温焙烤。
- 短芽麦芽损失小但溶解不足，只能配合很强的糖化程序；低温焙焦的糖化力麦芽保留了大量酶，可帮助分解辅料。
- 色素啤酒用约 40% 焙烤麦芽酿造，脱苦后真空浓缩到 1,000–17,000 EBC，能在任何工序调色，并且符合纯酒令。

**自测**

<details><summary>焦香麦芽和焙烤麦芽的根本区别是什么？</summary>

焦香麦芽先在滚筒里让籽粒内部糖化，再把糖焦糖化；焙烤麦芽是干麦芽直接高温焙烤。前者给焦糖香和酒体，后者给颜色和焙烤味，用量很小。

</details>
