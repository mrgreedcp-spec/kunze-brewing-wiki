# Kunze 酿造工艺 wiki

按 Wolfgang Kunze《Technology Brewing and Malting》（第 3 版国际版，VLB Berlin 2004）印刷页 p.32 起的顺序整理的中文学习笔记：从大麦到灌装共 6 个阶段、40 个工序。每个工序写明目的、关键参数、机理、常见问题和自测题。

交互版（图表、计算器、搜索）：[Kunze 酿造工艺图谱](https://claude.ai/artifact/18cgTT4TP39ZYKT4qf6q6u)（需登录 Claude 并获得分享权限；仓库中的 `site/index.html` 是同一页面，可直接用浏览器打开）。

## 怎么用

1. 先用上表把六个阶段串起来，再进入某一阶段按工序读。
2. 每个工序先读“目的”，再看“关键参数”，最后用“机理与要点”解释这些参数为什么是这样。
3. 读完一个工序就做它的自测题；术语不熟时查术语表。
4. 涉及计算的地方，先看公式页的示例，再用交互版计算器换成自己的数字。
