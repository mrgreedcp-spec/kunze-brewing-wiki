# 06 灌装与收尾（Filling, packaging, losses, cleaning）

> Kunze 原书印刷页 p.532–731 · [返回首页](README.md)

把清酒装进瓶、罐、桶，保住 CO₂、不进氧、不污染；再经贴标、装箱、码垛送出工厂，并用损耗、麦芽单耗和清洗体系把整条线闭环管起来。

- **输入**：清酒（0–1 °C）
- **输出**：瓶装、罐装、桶装成品；总氧 ≤0.10–0.15 mg/L
- **关键数字**：洗瓶 80–85 °C · 灌装吸氧 ≈0.02 mg/L · 损耗 8–10%

**本页工序**：[6.1 洗瓶与空瓶检验](#s6-1) · [6.2 灌装与压盖](#s6-2) · [6.3 贴标与日期标注](#s6-3) · [6.4 罐、PET 瓶与桶](#s6-4) · [6.5 输送、装箱与码垛](#s6-5) · [6.6 灌装线的整体设计](#s6-6) · [6.7 损耗、麦芽单耗与产能](#s6-7) · [6.8 清洗与消毒（CIP）](#s6-8) · [6.9 安全](#s6-9)

## 6.1 洗瓶与空瓶检验（Bottle washing, empty bottle inspection）

*Kunze p.532–564*

**目的**：让回收瓶干净、无菌、无残留地回到灌装机，并逐瓶剔除有缺陷或不干净的瓶子，同时控制用水、用热和化学品。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 碱液 | 1.5–2.0% NaOH（1.6% 最佳）加添加剂；第二碱槽 65–70 °C、0.6–0.8% |
| 温度 | 80–85 °C；升温一次跳跃 ≤30 K、降温 ≤20 K，防止爆瓶 |
| 碱浸时间 | 平均 6–7 min（80 °C 下 6–8 min，双端机必要时可到 25 min） |
| 流程 | 倒残液 → 预浸（约 40 °C）→ 预碱（约 60 °C）→ 主碱（80 °C）→ 碱喷 → 中间喷 → 温水喷 → 冷水喷 → 新鲜水喷 |
| 节拍与瓶笼 | 节拍约 3–4 s；200–600 个瓶笼，每排 16–40 瓶；节拍 4 s 时每个瓶位约 900 瓶/h，所以 5 万瓶/h 至少要 55 瓶/排 |
| 喷冲 | 约 2.0–2.5 bar，喷孔 2–4 mm；多数瓶口内径只有约 16 mm，限制了喷入量 |
| 带出量与消耗 | 带出量 10–20 mL/瓶（好的机器 &lt;8）；用水 200–250 mL/瓶；耗热 30–40 kJ/瓶（目标 &lt;35） |
| 洗后抽检 | 表面张力 &gt;55 mN/m，非离子表面活性剂 &lt;0.5 mg/L，瓶内 COD &lt;15 mg/L |
| 空瓶检验 | 5 万瓶/h 时每瓶只有约 0.07 s；残液检测永远双重（高频 + 红外）；约每 30 min 过一次测试瓶 |

**机理与要点**

- 回收瓶灌装的完整链条：分拣外来瓶和外来箱 → 检查回收瓶 → 洗瓶 → 空瓶检验 → 灌装压盖 → 液位检验 →（需要时）隧道杀菌 → 贴标 → 装箱码垛。
- 清洗效果来自四个要素相乘：化学（NaOH 与添加剂）、温度、时间和喷冲的机械作用。
- 单端机进出瓶在同一端，省地方、机身矮、便宜，但脏瓶进口挨着净瓶出口；双端机两端分开，出瓶端可以用隔墙与脏区隔开。瓶笼要略微倾斜：水平的瓶子既灌不满（气垫妨碍清洗），也排不净（带出碱液）。
- 30–50 °C 的温水喷淋区正好是细菌的最适温度，多孔水垢和机顶潮湿的空间也是菌窝 → 定期清洗；末道冲洗水常加少量 ClO₂（&lt;0.4 mg/L），出瓶处抽走蒸汽，防止冷凝水滴进净瓶。
- 标签要整张、尽快取出，泡久了会碎成浆：靠强力循环加筛网或筛带连续捞出，湿标签含碱，再经压榨（12–15 bar）脱水约 80%。铝箔遇碱放出氢气，要抽到室外，防止在机内形成爆炸性混合气。
- 空气中的 CO₂ 会把 NaOH 变成碳酸盐、降低清洗力 → 按电导持续补碱。碱液中的纸浆、颜料和胶会形成泥，可用沉降、离心或膜过滤去除；膜过滤能让碱液几乎无限期使用。
- 空瓶检验机用多台 CCD 相机和频闪灯“冻结”图像：外侧壁（擦伤环、残标）、瓶底（异物、碎玻璃、薄膜，PET 瓶的应力裂纹）、瓶口螺纹和密封面、内侧壁；残液用两种方法查：高频利用液体的介电常数是玻璃的 2–3 倍，红外看瓶底；还可剔除过高、过矮、异色、外来的瓶子。检验机本身要用测试瓶定期验证，误剔的好瓶也要统计。
- 5–7 次循环后瓶身涂层被洗掉，擦伤环越来越明显；棕色瓶对 350–500 nm 的光防护最好。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 洗后瓶内有残碱或表面活性剂，泡沫变差 | 冲洗不足、带出量大，残液检测失灵 | 检查喷嘴和冲洗水量；按表面张力和 COD 抽检；用测试瓶验证检验机 |
| 过滤后无菌，成品却检出杂菌 | 洗瓶机温水区、喷淋水或机顶冷凝水带菌 | 定期清洗温水区和机顶，末道水加 ClO₂，出瓶处抽蒸汽 |

**自测**

<details><summary>洗瓶机升温为什么要分几级？</summary>

玻璃怕温度骤变，一次跳 30 K 以上会产生热应力而爆瓶；预浸和预碱段既预热瓶子，又预先溶解污垢。

</details>

<details><summary>为什么残液检测要同时用高频和红外两种方法？</summary>

残碱会伤害消费者，而单一方法可能漏检（例如残标堵住瓶口、残液留在瓶里）；两种原理互相补充，才能可靠剔除。

</details>

## 6.2 灌装与压盖（Bottle filling, closing）

*Kunze p.564–599*

**目的**：用等压原理把啤酒灌进瓶里，尽量排尽瓶中空气并立即封口，再逐瓶检验；灌装区还要保持无菌。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 原理 | 等压（背压）灌装：瓶内气压与贮液缸相等时才开液阀；灌装压力要高于 CO₂ 饱和压力 |
| 灌装温度 | 冷灌 5–10 °C（最常见）；温灌 18–25 °C；热灌不用于啤酒 |
| 预抽真空 | 两次抽到约 90%（约 100 mbar），中间充 CO₂ → 瓶内空气降到原来的约 1% |
| 长管与短管 | 长管阀让酒从瓶底往上灌，吸氧最少，但瓶口窄、速度受限；“短管”阀的短管其实是回气管，酒沿瓶壁流下，要配合预抽真空，能力高，现在最常用 |
| 灌装吸氧 | 现代灌装机约 0.02 mg/L；灌装后总氧 ≤0.10–0.15 mg/L |
| 高压喷射（HDE） | 最高约 40 bar 的极细 80 °C 热水射入瓶口，使瓶颈起泡、把空气顶出 |
| 顶隙氧 | 0.33 L 瓶 ≤0.06 mg；0.5 L 瓶 ≤0.08 mg |
| 液位精度 | 0.5 L 瓶多灌 1 mL，年灌 10 万 hl（2000 万瓶）就是 200 hl |
| 灌装机 | 旋转式，最多约 200 个阀；单次灌装 5–6 s；可超过 10 万瓶/h |
| 皇冠盖 | 26 mm 规格、21 个齿；压盖时盖进入压盖环 7.7 mm，封口直径 28.6–28.7 mm；带除氧剂的垫片可结合 2–4 mg O₂ |
| 灌装区冲淋 | 易污染部位约每 2 h 用 80–95 °C 热水冲淋一次，停机或半速时冲 2–3 转，用宽水流而不是雾化喷雾 |

**机理与要点**

- 计算机控制的短管阀一个循环：压紧 → 第一次抽真空 → CO₂ 冲洗 → 第二次抽真空 → 背压到与缸等压 → 快灌（酒经分流锥沿瓶壁成薄膜流下）→ 慢灌 → 探头到位结束 → 经锥形细通道缓慢卸压，防止冒泡；每周一次 CIP，阀下放假瓶。
- 定量方式：液位（回气管或探头，最常用）、容积（电磁流量计 IDM）、质量（多用于桶）。少灌是欺骗消费者和税务，多灌损失利润。
- 灌装阀的演变：旋塞式（1950 年代前，残酒会被带进下一瓶）→ 外部驱动阀（酒接触弹簧等内件，不卫生）→ 气动膜片阀（阀内没有弹簧）；换瓶型时用丝杠把环形缸和阀整体升降。
- 罐和 PET 瓶是薄壁容器，不能抽真空（会瘪），只能 CO₂ 冲洗预压或用长管灌装。HDE 的水量要恰当：太多反而带进氧，泡太多又损失啤酒；研究表明使用 HDE 时生成的 Strecker 醛更少。
- 灌后检验：液位（γ 射线、X 射线、高频或红外），同时剔除缺盖、歪盖；电磁脉冲让盖子中心振动，可以判断瓶颈是否充满细泡、盖是否密封。
- 压盖后要冲净盖下的残酒并吹干，否则齿下积水会生锈，存久了在瓶口下形成锈环；皇冠盖用磁性带输送、放在塑料容器里，互相磨下的漆屑会漂在酒面上且无法去除，所以料斗液位要设低。摇摆盖（瓷头 + 橡胶垫）封盖机复杂、橡胶垫易藏菌和串味，只用于高价特色酒。
- 灌装区的污染机理：醋酸菌到处都有，外面包着黏液荚膜，能抗干燥、热和消毒剂；荚膜里的氧被耗尽后，严格厌氧的 Pectinatus、Megasphaera 在其中定居，乳酸菌产生的乳酸又促进它们。对策：灌装机和压盖机闭路 CIP、定期热水冲淋、清理全线的“菌窝”（星轮、链道、盖板、砖缝、地沟），先喷一层硅藻土粉能找出喷淋死角。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 液位高低不齐 | 探头或阀门故障、回气管堵塞，HDE 水量过大使泡沫溢出 | 逐阀检查并调整 HDE；按阀号统计液位 |
| 压盖后漏气或很难开启 | 压盖直径不对（压盖头磨损或调整不当） | 用通止规逐个压盖头检查 |
| 瓶口下出现锈环 | 压盖后没有冲净吹干，仓库里有冷凝水 | 压盖后冲淋并吹干，仓库通风 |

**自测**

<details><summary>啤酒灌装为什么一定要等压？</summary>

啤酒是 CO₂ 过饱和溶液，常压下灌会立刻大量起泡，既灌不满又跑 CO₂；先让瓶内建立与缸内相同的 CO₂ 压力，啤酒才能平稳流入。

</details>

<details><summary>为什么“短管”灌装一定要预抽真空？</summary>

酒沿瓶壁流下，会和瓶内的气体接触；只有先把空气抽走、换成 CO₂，吸氧才能压到很低。

</details>

<details><summary>灌装区的厌氧菌为什么能在有空气的地方存活？</summary>

它们躲在醋酸菌的黏液荚膜里；醋酸菌耗尽荚膜里的氧，形成厌氧的小环境，还挡住了干燥、热和消毒剂。

</details>

## 6.3 贴标与日期标注（Labelling, dating）

*Kunze p.604–611*

**目的**：把标签牢固、端正地贴在规定位置，印上日期和批号；同时保证标签在下一轮洗瓶时能完整、快速地脱落。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 标签纸 | 单面涂布上光（金银色要金属化）；加钛白并全施胶，干湿都不透底；背面也要处理以防卷曲；Cobb 吸水值约 16–20 g/m² |
| 纤维方向 | 与瓶轴垂直，洗瓶时更容易脱标 |
| 贮存 | 60–70% 相对湿度、20–25 °C，保持平整 |
| 标签胶 | 约 90% 酪蛋白胶，约 9.5% 淀粉胶，其余为合成胶 |
| 酪蛋白胶 | 黏度随温度变化大且有触变性 → 恒温 25–38 °C、用黏液泵循环；可用到约 8 万瓶/h；适合冷瓶、湿瓶 |
| 用胶量 | 约 8–15 g/m² |
| 日期 | 德国须标最佳食用期；国外越来越多标灌装日，并建议 90–110 天内饮用 |
| 激光打码 | 红外脉冲最高约 6 J、约 2 µs，经金属掩模打出字样；要抽走产生的臭氧 |

**机理与要点**

- 标签位置：身标、背标、胸标、颈标，环绕标越来越多。标签要耐碱、在洗瓶机里整张脱落；美、英、丹麦等国则要求标签碱溶成浆，前提是洗瓶机能处理纸浆、废水也允许。
- 贴标过程：上胶辊给胶片涂上薄胶 → 胶片滚过标签盒、粘起一张标签 → 打日期 → 夹指滚筒夹住没上胶的部位转交 → 贴到转盘上的瓶子并刷平。控制要做到“无瓶不取标”，断瓶后降到最低速。
- 胶的规律：黏度越高，初始黏着越快；酪蛋白越多，5 min 后越牢；胶层越薄，越耐冷凝水；胶层越薄、pH 越低，在碱槽中脱标越快。太厚脱标慢、易脏，太薄黏不牢、会滑移。淀粉和糊精胶对温度不敏感，适合温瓶、热瓶。
- 印刷颜料除蓝色（含铜络合物）外不含重金属；银色以铝为基；胶印金色用铜锌合金。
- 封颈箔（金色或银色铝箔）紧接在贴标之后、与出瓶星轮同步贴上。日期可用打码、在标签边缘切口、压凹或打孔、喷墨或激光。
- 一次性玻璃瓶由玻璃厂成托盘供货，基本干净，只需逐层卸垛，再在冲瓶机里瓶口朝下冲 8–10 s（有时省略）。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 标签在洗瓶机里碎成浆 | 标签不耐碱、在碱槽里泡得太久、纤维方向不对 | 选耐碱标签；加强碱液循环，尽快把标签捞出 |
| 标签起皱、翘边或滑移 | 胶量太多或太少、胶温不对、瓶面有冷凝水 | 控制胶温和用量；潮湿的冷瓶用耐冷凝水的胶 |

**自测**

<details><summary>为什么标签纸的纤维要与瓶轴垂直？</summary>

洗瓶时标签吸碱后更容易卷起、整张脱落，不会碎成纸浆。

</details>

<details><summary>酪蛋白胶为什么必须恒温？</summary>

它的黏度强烈依赖温度，而且越搅越稀（触变性）；温度一变，上胶量和黏着力就跟着变。

</details>

## 6.4 罐、PET 瓶与桶（Cans, PET, kegs）

*Kunze p.611–679*

**目的**：按容器特点调整灌装：罐和 PET 怕压、怕真空，PET 还透气；桶要全自动清洗灭菌，并靠内压证明自己密封。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 罐 | 耐内压 ≥6 bar；罐壁约 0.09 mm（钢）/0.11 mm（铝）；铝罐 330 mL 约 12 g |
| 罐装 | 阀下降压到罐上（罐不抬升）；CO₂ 冲洗预压，液膜沿罐壁灌入，约 5 s 灌完；总氧可达约 0.02 mg/L（耗 CO₂ 0.6–0.8 kg/hl）；盖下充 CO₂ 后两道卷封 |
| 容积式罐装 | 细长计量腔预先量好（超声浮子，精度 &lt;1.5 mL），开阀后全速灌入，不需要末段减速 |
| 罐的液位 | 罐径 66 mm 时高度差 1 mm ≈ 3.4 mL（约为 0.33 L 罐的 1%） |
| PET | 0.5 L 瓶 &lt;30 g；透氧、失 CO₂，需要阻隔涂层、多层结构或除氧剂；啤酒用 PET 只做一次性瓶 |
| PET 灌装 | 不能抽真空：短管阀用 CO₂ 吹出空气（CO₂ 约 600 g/hl，预抽真空的玻璃瓶约 250 g/hl，吸氧约 0.08 mg/L）；长管阀可用 CO₂ 预压，吸氧约 0.02 mg/L |
| 塑料螺旋盖 | 聚丙烯两件式，垫料含除氧剂（结合 2–4 mg O₂）；盖本身带进约 5 mL 空气（铝盖约 3 mL） |
| PEN | 阻气性好、耐热、可巴氏杀菌，价格约为 PET 的 5 倍，约可循环 20 次，是唯一的塑料回收啤酒瓶 |
| 桶（Keg） | 不锈钢 1.4301/1.4306，常用 30 L 和 50 L；矛管直达桶底；始终带压；灌装吸氧 ≤0.1 mg/L |
| 桶线能力 | 直线式约 300 桶/h；旋转式最多约 1,000 桶/h |

**机理与要点**

- 罐的刚性来自内压，空罐一碰就瘪，而且变形会传给相邻的整排：叉车要轻进轻出，运输中损坏的罐要在进提升井前剔除，凹罐绝不能压回去；卸垛时整层平推，罐挤在一起才站得稳。空罐检验查圆度、翻边、罐壁和罐底变形、内涂层缺陷和异物——罐口不圆会撞坏封罐机。
- 罐的贴标用卷筒环绕标（热熔胶涂在首尾，约 4.5 万罐/h，只贴已封口的罐）；日期用喷墨印在罐底，最好在卸垛后罐底还干的时候打。非碳酸饮料要滴一点液氮建立内压；充氮胶囊（widget）开罐时释放氮气，形成细腻的泡沫。
- PET 瓶由瓶坯在线拉伸吹塑：加热 → 拉伸杆把瓶坯拉长 → 吹气成形 → 冷却定形；吹后立即检查瓶底、密封面和侧壁。瓶子很轻、在输送带上易倒，所以挂着瓶颈环在风送道里输送；新瓶一般不冲洗（每滴水都会带进氧）。
- PET 会吸附香气成分、使用后出现应力开裂而无法洗净，所以不适合做回收瓶。HDE 使泡沫升到螺纹里会长霉 → 先盖预封片、冲净螺纹再旋盖。回收塑料瓶洗瓶温度不得超过 60 °C（PEN 可 75–80 °C），洗前还要用“嗅探器”剔除装过汽油、溶剂的瓶子。
- 桶线：翻转（阀朝下）→ 去帽 → 压力检查（失压说明泄漏、阀坏或被动过）→ 排残 → 外洗 → 水、碱、酸、热水脉冲冲洗 → 蒸汽灭菌并检漏 → CO₂ 吹出蒸汽并预压 → 灌装（慢起步、快主灌、慢收尾）→ 称重或 γ 射线查液位 → 翻正 → 戴帽。
- 自冷桶（5–20 L）：打开阀门后，外层真空里的沸石吸水，使中层含水层的水蒸发吸热，约 30 min 后可饮，6–9 °C 能维持约 12 h；再生要把外壳加热到约 250 °C，所以桶身不能印刷。5 L 聚会罐要用能补气保压的放酒装置，喝到最后酒也不会“死”。

**自测**

<details><summary>回收的空桶为什么先要测内压？</summary>

桶离开市场时仍然带压，外界的东西进不去；压力消失说明桶漏、阀坏或被人动过，必须先查明原因。

</details>

<details><summary>容积式罐装为什么比按液位灌装快？</summary>

计量在换罐的时间里已经完成，灌装时可以一直全速，不必在接近液位时减速。

</details>

## 6.5 输送、装箱与码垛（Conveying, packing, palletising）

*Kunze p.679–702*

**目的**：让瓶、罐、箱和托盘平稳、安静、不擦伤地到达每台机器，并把成品可靠地装箱、码垛、固定后送出工厂。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 包装形式 | 塑料周转箱（回收瓶唯一的包装，6–24 瓶、0.25–1 L）、折叠纸箱、托盘纸板加收缩膜、六联包（4–8 件） |
| 托盘 | 欧洲托盘 800 × 1200 mm；纸箱类各层纵横交错以提高稳定性 |
| 装箱节拍 | 5 万瓶/h、每箱 20 瓶 → 每小时 2500 箱，每分钟约 42 箱，每秒约 0.7 箱 |
| 瓶罐流量 | 5 万瓶/h 时每秒约 14 瓶要连续通过检验、灌装和压盖 |
| 链道润滑 | 肥皂 → 加硬度螯合剂（会从污泥中释放重金属，多国已禁）→ 含胺润滑剂 → 可生物降解的无胺非离子表面活性剂；塑料链可干跑或只喷水 |
| 收缩包装 | PE 膜的生产耗能约为纸的 1/3，用料约为纸板的 25%；包好后稳定，不需隔板 |
| 托盘库 | 空托盘最多叠约 15 个；满垛可由叠垛机叠 2–3 层 |

**机理与要点**

- 企业专用箱广告效果好，但必须回到本厂（麻烦、有成本）；共用箱放弃广告，可开窗露出标签（对标机把标签转向箱窗）。20–24 瓶的大箱太重（空瓶箱几乎和内容物一样重），小箱越来越多。
- 进厂的空瓶箱要检查瓶高、颜色、残留瓶盖，以及箱色、标志、提手孔裂纹、箱内杂物和碎瓶；出厂前的满箱检查缺瓶、少灌、缺盖和破损漏酒——这些错一定出在厂内。洗箱机是箱子倒扣通过的隧道，用碱液或热水喷洗；换品种时空箱先进箱库等待，否则会堵住箱流。
- 不锈钢板链在弯道和多道输送上会让瓶子互相推挤、转动，形成擦伤环；单列器靠很小的带速差把多道瓶流无背压地排成一列，PET 瓶和底径 &lt;60 mm 的瓶用平行移位输送。链道框架内要装喷淋自动清洗，用焊接代替螺栓、减小接触面、不留水平面，否则会成为向灌装机扩散的菌窝。
- 装箱机的抓头数量和排列必须与箱格一致（4 × 5 = 20 瓶），换箱型就要换装。机械式抓头夹住瓶口（不能碰坏封箔和防盗标），气动式用气囊推动软指夹住瓶颈。类型有间歇式、连续回转式、多件包装机、组合式（一个循环先卸后装，省去洗箱）和对标机；卸箱前提是箱里没有异型瓶、瓶上没有残留瓶盖。
- 码垛越来越多用机器人（2 轴直线、3 轴旋转臂、6 轴关节臂）。装载头按包装选：钩式、层夹式、直接抓瓶的抓瓶头式、充气管夹瓶颈式、吸盘式（纸箱）、磁力式（钢罐）、桶用夹头。托盘要检查面板、角墩和尺寸；满垛用顶层打包带、缠绕膜或收缩膜固定，纸箱可喷防滑剂。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 瓶身擦伤环越来越重 | 多道链上瓶子互相推挤、转动，转弯太多，背压太大 | 用单列器和无压缓冲，减少转向；选用带擦伤凸环的瓶形 |
| 地面积泡沫，废水负荷升高 | 链道润滑剂加得太多 | 自动定量加入；改用可干跑的塑料链 |

**自测**

<details><summary>为什么越来越多的酒厂把链道换成塑料链？</summary>

塑料链可以干跑或只喷水，不用润滑剂：地面不起泡、废水负荷低，也省化学品。

</details>

<details><summary>卸箱机为什么要求瓶上不能有残留的瓶盖？</summary>

抓头要从瓶口抓起空瓶，残留的皇冠盖会让抓瓶失败或损坏抓头，这些瓶子还要单独处理。

</details>

## 6.6 灌装线的整体设计（The filling line as a whole）

*Kunze p.702–708*

**目的**：把几十台机器连成一条稳定运行的线：灌装压盖机是核心，其余设备的能力和缓冲段都为它连续运行服务。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 缓冲段 | 多道缓冲加单列器；约半满运行，料位用来自动调节各机的速度 |
| 三个循环 | 托盘循环（可作干区）、箱循环、瓶循环（最长，经过全部工序） |
| 布置形式 | 直线式（少见）、梳式（最常见，缓冲段长）、竞技场式（环形，省地方） |
| 成品库 | 按品牌存放、防冻、库存 2–3 天、先进先出；叉车堆垛的地面利用率只有 50–60%，所以大厂用高架库 |
| 德国标准 | DIN 8782（灌装术语）、DIN 8783（设备检验）、DIN 8784（订货信息）、DIN 55405（包装术语） |

| 设备 | 设计能力（灌装压盖机 = 100%） |
| --- | --- |
| 卸垛机 | 135–140% |
| 卸箱机 | 120–125% |
| 洗瓶机 | 110–115% |
| 空瓶检验机 | 110–115% |
| 灌装压盖机 | 100% |
| 贴标机 | 110–120% |
| 装箱机 | 120–125% |
| 码垛机 | 135–140% |

**机理与要点**

- 灌装车间连同输送和堆场，是全厂最大、最贵、用人最多的部分。
- 能力分级（书中称 Berg 曲线）：离灌装机越远，设计能力越高。这不是让卸垛机一直以 140% 运行（那样会堵），而是保证短暂故障过后，上游能尽快把缓冲段重新填满，下游能尽快把积压的瓶子排空。
- 布置时让操作工看得见全线，不必钻过或跨过几条输送线就能到达机器；设备要便于维修；尽量把干区和湿区分开；少让瓶子转动互相摩擦。
- 空瓶库要保证同品牌、同瓶型的空瓶连续供应，否则灌装线会因为缺合适的空瓶而停下来。

**相关工具**：[计算：灌装线能力分级（Berg 曲线）](tools.md#berg)

**自测**

<details><summary>缓冲段为什么要半满运行？</summary>

上游停机时，缓冲段里还有瓶子可供灌装机；下游停机时，缓冲段还有空间接住灌好的瓶子。两头都要留余地。

</details>

<details><summary>为什么说灌装压盖机决定整条线的产量？</summary>

它是全线的核心和瓶颈，它一停，上游积瓶、下游断料；其他设备都按比它高的能力配置，就是为了让它尽量不停。

</details>

## 6.7 损耗、麦芽单耗与产能（Losses, malt usage, capacity）

*Kunze p.333–334、709–715*

**目的**：用三套相互独立的数字检查整个工厂：糖化间收率管粉碎到定型，啤酒损耗管定型到可售啤酒，麦芽单耗管全过程。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 啤酒损耗 | 平均 8–10%（占定型麦汁） |
| 损耗构成 | 冷缩约 4%（体积收缩）、开放冷却蒸发 2.5–3.0%、发酵间 1.3–1.7%、贮酒 0.6–0.8%、过滤 0.8–1.0%、灌装 0.2–0.8% |
| 麦芽单耗 | 6% 啤酒约 9 kg/hl，11% 约 17 kg/hl，16% 约 26 kg/hl |
| 滴漏 | 每秒一滴（0.05 mL），一年约 15.8 hl |
| 过滤损失 | 板框约 0.4–0.8%，烛式约 0.3%；现代灌装车间 0.2–0.4% |
| 产能经验 | 每天 8 批、每周 5 天时，每 1 t 投料能力约对应每年 10 万 hl 啤酒 |

**机理与要点**

- 可售啤酒产量 = 本期销量 + 期末库存 − 期初库存；库存要按各工段的经验损耗折算成“可售啤酒”再相加。
- 麦芽单耗最难被操作参数“修饰”，最能客观反映全厂水平；但收率和损耗的百分数不能相加。
- 常见损失点：容器壁、长管道、漏点，酒花糟和凝固物带走的麦汁，溢出的泡沫，撇泡沫盖（每 100 hl 损失 10–20 L），沉降不紧的酵母；回用酵母尽量“干”加入下一批。

**相关工具**：[计算：啤酒损耗与麦芽单耗](tools.md#loss) · [计算：糖化间年产能](tools.md#cap)

**自测**

<details><summary>为什么说麦芽单耗“不能被操纵”？</summary>

它直接用投进去的麦芽除以卖出去的啤酒，中间任何收率或损耗的算法调整都绕不过去。

</details>

## 6.8 清洗与消毒（CIP）（Cleaning and disinfection）

*Kunze p.716–731*

**目的**：让所有接触产品的表面保持清洁无菌；材料、药剂、程序和管道设计必须互相匹配。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 典型 CIP 程序 | 回收水预冲 3–5 min → 1–2% NaOH 70 °C 循环 30–50 min → 中间冲洗 → 1–2% 硝酸 10–15 min → 冲洗 → 消毒 15–20 min → 新鲜水终冲；合计 1–2 h |
| 锥形罐酸性一步法 | 预冲约 10 min → 酸约 60 min → 冲洗 5 min → 消毒 15 min → 新鲜水 10 min；可在 CO₂ 气氛下进行 |
| 糖化容器 | 2–3% NaOH 加氧化性添加剂，再做短时酸洗 |
| 过氧乙酸 | 0.01–0.1%，分解后无残留 |
| 喷淋 | 以低压喷淋为主（≤6 bar，20–75 m³/h）；高压喷射最高约 60 bar |
| 回流泵 | 能力比送液泵高约 25% |
| 材料 | CrNi 钢（1.4301/1.4306）不耐含氯药剂；含氯场合用 CrNiMo 钢（如 1.4404、1.4571） |

**机理与要点**

- 分区设 CIP 站：糖化间与麦汁管路、未滤啤酒管道、未滤啤酒罐、滤后啤酒与灌装，防止污染跨区传播。
- 热碱遇 CO₂ 生成碳酸盐而失效；锥形罐要先排 CO₂，而且清洗温度通常 ≤35 °C（冷液喷淋热罐会造成真空内爆）。酸性一步法同时避开了这两个问题。
- 啤酒石是微生物的藏身处，用稀硝酸去除；季铵盐难冲净，长期使用会培养出耐药的腐败菌；次氯酸盐绝不能与酸混用。
- 管道设计缺陷（死角、没排气的高点、下垂积液段、变径、三通阀）会让 CIP 失效。
- 配制化学品永远“先水后酸碱”，并戴护目镜。

**自测**

<details><summary>锥形罐为什么很少用 80 °C 以上的热碱清洗？</summary>

罐里残留的 CO₂ 会把 NaOH 变成碳酸盐，清洗力下降；而且热罐被冷液喷淋时气体收缩、蒸汽冷凝，会产生真空，大罐可能被吸瘪。

</details>

## 6.9 安全（Safety at work）

*Kunze p.187–188、359–360、523–526*

**目的**：记住酒厂里几类会致命的风险：CO₂、粉尘爆炸、运动机械、受限空间与压力容器、化学品、硅藻土粉尘。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| CO₂ | 德国车间限值 0.5% vol（短时 1.0%）；&gt;2% 呼吸加快、出现视觉障碍；8–10% 失去意识直至死亡 |
| 进罐前 | 抽吸或冲洗到 ≤0.5%（短时 1.0%）；书面许可、指定监护人、安全联络岗；用气体检测仪 |
| 粉尘 | 粒径 &lt;100 µm、浓度约 20–2,000 g/m³ 时可爆；混合物约 400 °C 以上被点燃，薄层粉尘在 200 °C 以下的热表面上就能着火 |
| 锥形罐人孔 | 上下各至少 450 mm；从上方进入须系安全带和绳，禁用绳梯和移动梯 |
| 压力容器 | 液面上方可能出现 &gt;0.1 bar 过压的容器都属压力容器 |

**机理与要点**

- 典型事故模式：一个人留下“我自己弄完”，CO₂ 让人逐渐无力、跪倒，在罐底更高的浓度中窒息；周一早上开工前 CO₂ 浓度最高。
- 进入带搅拌器、耕糟机或翻麦机的设备前，拔下保险或控制钥匙随身带着，防止被人误启动。
- 离心分离机必须按标记位置装配；不平衡的转鼓一旦解体，破坏半径很大。

**自测**

<details><summary>为什么“放下点燃的蜡烛”不能用来判断发酵罐能否进入？</summary>

蜡烛要到 CO₂ 约 8–10% 才熄灭，而这个浓度已经足以让人失去意识。

</details>
