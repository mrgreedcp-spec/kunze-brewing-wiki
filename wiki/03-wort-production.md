# 03 麦汁制备（Wort production）

> Kunze 原书印刷页 p.195–366 · [返回首页](README.md)

在糖化间把麦芽中不溶的淀粉和蛋白变成可溶浸出物，分离酒糟，煮沸加酒花，去除凝固物，再冷却充氧。这一阶段决定可发酵糖比例、苦味、DMS 和热负荷。

- **输入**：麦芽（和辅料）、酿造水、酒花
- **输出**：接种麦汁：如 11–12 °P，5–8 °C，溶氧 8–10 mg/L
- **关键数字**：糖化 62–78 °C · 煮沸 40–60 min · 收率 74–79%

**本页工序**：[3.1 粉碎](#s3-1) · [3.2 糖化](#s3-2) · [3.3 辅料糖化与特殊糖化法](#s3-3) · [3.4 过滤](#s3-4) · [3.5 麦汁煮沸与加酒花](#s3-5) · [3.6 糖化间收率](#s3-6) · [3.7 回旋沉淀与热凝固物](#s3-7) · [3.8 冷却、充氧与冷凝固物](#s3-8)

## 3.1 粉碎（Milling）

*Kunze p.196–214*

**目的**：把胚乳粉碎得足够细，便于酶作用；同时尽量保护谷皮，让它在过滤槽里继续充当滤层。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 六辊典型辊距（过滤槽粗粉） | 预碎辊 1.2–1.6 mm，皮辊 0.6–0.8 mm，粒辊约 0.4 mm；压滤机粉更细 |
| 辊 | 直径约 250 mm，长 0.8–1.0 m；600–900 条斜齿纹，两辊转速比约 1.25 : 1 |
| 调湿粉碎 | 粉碎前 1–2 min 用 30–35 °C 蒸汽或水；谷皮水分 +1.2–2.5%，籽粒内部仅 +0.3–0.5% |
| 浸渍调湿 | 60–70 °C 水接触 50–60 s（要抑制脂氧合酶可用 80 °C） |
| 粉的体积 | 未调湿 0.5–0.7 hl/100 kg；调湿 0.8–1.0 hl/100 kg |
| 筛分检验 | 6 级筛：谷皮、粗粒、细粒 I、细粒 II、粉、细粉；锤磨粉的谷皮部分只有约 1% |
| 粉尘 | 0.4–1.4 kg/100 kg 麦芽 |

**机理与要点**

- 矛盾在于：粉越细酶作用越充分，但过滤槽需要完整的谷皮做滤层。湿而有弹性的谷皮加上干而脆的胚乳是理想状态，这就是调湿粉碎。
- 溶解差的麦芽要磨得更细；溶解好的麦芽、强糖化法、过滤时间长时可以粗一些。
- 压滤机靠薄滤饼和聚丙烯滤布过滤，不依赖谷皮，可以用锤式粉碎机磨得很细，收率更高。
- 粉碎一开始脂氧合酶就被激活 → 粉仓和调湿段可以充惰性气体，投料尽快进行。
- 防爆：辊下防爆板、泄爆片、Q 管或抑爆系统，设备良好接地。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 过滤慢、酒糟压实 | 粉太细或谷皮破碎太多 | 放大辊距，采用调湿粉碎 |
| 酒糟可提取浸出物高 | 粉太粗、辊磨损、麦芽太湿 | 调整辊距、重磨辊子、放慢粉碎 |

**自测**

<details><summary>调湿粉碎为什么能同时提高过滤速度和收率？</summary>

润湿的谷皮有弹性、不易碎，体积增加 10–20%，滤层更松；胚乳仍然干脆，可以磨细，酶作用面更大。

</details>

## 3.2 糖化（Mashing）

*Kunze p.214–247*

**目的**：让麦芽中的酶在各自最适条件下，把淀粉分解成糖和糊精，分解 β-葡聚糖和蛋白，并按啤酒类型设定可发酵糖的比例。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 休止温度 | 45–50 °C 蛋白与 β-葡聚糖；62–65 °C 麦芽糖（β-淀粉酶）；72–75 °C 糖化（α-淀粉酶）；76–78 °C 终止 |
| 糊化温度 | 有淀粉酶存在时麦芽和大麦淀粉约 60 °C；大米 80–85 °C |
| 可发酵糖（淡色全麦） | 占浸出物 62–68%；其中麦芽糖约 65%、麦芽三糖约 17.5%、葡萄糖和果糖约 12%、蔗糖约 5% |
| 料水比 | 淡色 3–4 hl/100 kg；深色 3–3.5 hl/100 kg；醪比成品原麦汁浓 5–6% |
| 目标醪 pH | 5.1–5.2（未处理时通常 5.6–5.9） |
| 麦汁 FAN 与锌 | FAN 约 200–230 mg/L（12%）；锌 ≥0.10–0.15 mg/L |
| 搅拌 | 周速 ≤2 m/s（最高 3），为防剪切宜 &lt;1 m/s |
| 糖化时长 | 浸出法 1.5–2 h；煮出法最多约 3 h |

**机理与要点**

- 淀粉分解三步不能颠倒：糊化（淀粉粒吸水膨胀破裂）→ 液化（α-淀粉酶迅速降低黏度）→ 糖化（α-淀粉酶切成 7–12 个葡萄糖的糊精，β-淀粉酶从链端切下麦芽糖）。两种淀粉酶都切不开 1,6 支点，所以总会留下界限糊精。
- 碘检：冷却的醪样滴 0.02 N 碘液不再变色即“碘正常”。若到定型麦汁仍显蓝色，只能补加头道麦汁或麦芽浸出物来补救。
- 62–63 °C 长休止 → 麦芽糖多、发酵度高；以 72–75 °C 为主 → 糊精多、发酵度低。醪较稠时酶受保护，发酵度略高；较稀时浸出更多。
- β-葡聚糖：内切葡聚糖酶最适 45–50 °C（40–45 °C）而且怕热；耐热的溶解酶（约 62 °C）只释放不分解 → 溶解差的麦芽不适合高温投料。泵、急弯、剧烈搅拌产生的剪切力会让 β-葡聚糖交联成凝胶。
- 蛋白：45–50 °C 生成较多氨基酸（酵母营养），60–70 °C 生成较多高分子产物（泡沫）。溶解好的麦芽再做长时间 50 °C 休止，泡沫反而变差。
- 脂氧合酶在低温、较高 pH 的投料阶段最活跃 → 高投料温度（≥60 °C）、低 pH（5.1–5.2）、避免进氧都能保护风味稳定性。
- 生物酸化：培养麦芽自带的乳酸菌（如 L. amylovorus，48 °C），得到 0.8–2% 的乳酸液；每把 pH 降 0.1，醪中约需 60 mL/kg 麦芽的 0.8% 乳酸液（加在麦汁中约需一半）。纯酒令下这是唯一合规的降 pH 方法。
- 煮出法永远煮稠醪：稠醪里是尚未溶解的颗粒，需要煮沸破开淀粉；稀醪溶有大量酶，一煮就失去酶。回混时把煮沸醪泵入未煮醪，并尽量从底部进入以免吸氧。

**相关工具**：[数据：主要酶的最适温度](programmes.md#enzymes) · [数据：糖化程序](programmes.md#mash) · [计算：投料水与头道麦汁浓度](tools.md#water) · [计算：煮出醪量](tools.md#decoct)

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 碘反应不正常 | 糖化温度过高或时间不足；终止温度过高使 α-淀粉酶失活 | 延长 72 °C 休止；终止温度不超过约 78 °C |
| 发酵度偏低 | 麦芽糖休止不足 | 延长 62–64 °C 休止 |
| 泡沫差、口感空 | 50 °C 休止太长，蛋白分解过度 | 缩短或取消低温蛋白休止，提高投料温度 |
| 过滤困难 | β-葡聚糖高、剪切过大 | 检查麦芽溶解；降低搅拌和泵速，避免急弯 |

**自测**

<details><summary>为什么终止温度一般不超过 78 °C？</summary>

过滤中还会溶出少量未分解的淀粉，需要仍然有活性的 α-淀粉酶完成后糖化；超过约 78–80 °C 它迅速失活，麦汁可能不再碘正常，形成淀粉浑浊。

</details>

<details><summary>高温投料（60–64 °C）的前提是什么？</summary>

麦芽必须溶解得非常好而且均匀（脆度 &gt;85%、均一性 ≥70%、协定麦汁黏度 &lt;1.6 mPa·s），否则 β-葡聚糖得不到分解，过滤出问题。

</details>

<details><summary>为什么煮出法比浸出法多耗 10–20% 的能量？</summary>

除了把全醪升温，还要把相当一部分稠醪单独加热到沸腾并保持一段时间。

</details>

## 3.3 辅料糖化与特殊糖化法（Adjuncts, special mashing）

*Kunze p.245–255*

**目的**：处理糊化温度高、没有经过制麦的谷物；或者用特殊程序得到特定的发酵度或收率。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 大米 | 米粉加 10–20% 麦芽粉，每 100 kg 至少 5 hl 水；78 °C 液化 10–20 min，或 85–90 °C 糊化后兑入较冷的麦芽醪到 72–75 °C，再煮沸 30–40 min |
| 玉米片 | 已压片糊化，可直接投入糖化锅 |
| 高粱 | 可用 100% 高粱麦芽；52 °C、pH 约 4.6 保证 FAN |
| 酶制剂 | 耐热细菌 α-淀粉酶（80 °C 以上仍有效）、蛋白酶、葡聚糖酶（纯酒令不允许） |
| 跳跃糖化 | 约 35 °C 稠醪中注入沸水，直接升到约 72 °C → 发酵度极限约 40% |
| 麦芽糖酶休止 | 45 °C → 葡萄糖可达 35–40%，乙酸异戊酯等酯香增加 70–120% |
| 加压糖化 | 2–3 bar 可多得 2–3% 收率，但额外浸出物质量差 |
| 糖化时长约束 | 每天 8 批须每 3 h 投料和定型；12 批则每 2 h |

**机理与要点**

- 米淀粉糊化后黏度极高：先与一部分麦芽醪一起升温，让 α-淀粉酶把它液化，再煮沸，最后兑入主醪。
- 辅料比例越高，麦汁的 FAN、多酚越少，口味越淡——从一开始就要考虑与全麦芽竞品的差别。
- 每天批次越多，越需要精确到分钟的程序和计算机控制。

**自测**

<details><summary>跳跃糖化为什么能得到低发酵度的麦汁？</summary>

它直接越过了 β-淀粉酶最适的 62–65 °C，只让 α-淀粉酶在 72 °C 工作，于是生成大量不可发酵的糊精。

</details>

## 3.4 过滤（Lautering）

*Kunze p.255–281*

**目的**：把麦汁和酒糟分开，再用洗糟水把酒糟里的浸出物洗出来；速度、清亮度和收率三者都要顾到。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 头道麦汁 | 比定型麦汁高 4–6%（12% 啤酒约 16–20%） |
| 温度 | 全程接近 78 °C，不超过约 80 °C |
| 假底负荷 | 干法粉 140–175 kg/m²；调湿 150–210；浸渍调湿 200–280 |
| 假底 | 缝宽 0.7–0.9 mm，开孔率 8–12%，距槽底约 20 mm |
| 进醪 | 从底部进，10 min 内完成，进口流速 ≤1 m/s |
| 酒糟静置 | 5–30 min（150 kg/m² 时糟层约 25 cm） |
| 残糖水 | 洗到约 2%（最多 3%）就停 |
| 2 h 节奏 | 准备和进醪 15 min + 头道麦汁 45 min + 洗糟 45 min + 排糟清理 15 min |
| 压滤机 | 糟层约 4 cm，周期 100–110 min，每天可做 12 批；滤布寿命 2,000–3,500 批 |
| 酒糟 | 每 100 kg 麦芽得 100–130 kg 湿糟（水分 70–80%），约合每 hl 啤酒 21–22 kg |

**机理与要点**

- 过滤槽顺序：排气（热水从下面顶满假底）→ 进醪 → 静置 → 回流浑浊麦汁 → 头道麦汁 → 洗糟（二道麦汁）→ 排糟。
- 静置后酒糟分三层：底层面团、主层、顶层面团（蛋白和细谷皮，透性差，要尽早打破）。
- 抽吸会把酒糟压实，所以按压差控制耕刀：压差升高就降刀松糟，浊度升高就抬刀。
- 分次小洗比连续洗收率高；连续洗更清亮、少浸提谷皮、少吸氧。
- 洗糟后期多酚、苦味物和硅酸溶出越来越多，所以不要过度洗糟，也不要轻易回用残糖水。
- 从上方抽出头道麦汁再精滤，可缩短约 20 min 而不损失收率。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 酒糟可洗出浸出物高（&gt;0.8%） | 麦芽溶解差、粉太细、洗糟太快、醪分布不均、酒糟压实、头道麦汁太稀、过滤太冷 | 用溶解好的麦芽，调粗粉碎，保证洗糟时间，均匀布醪，控制抽吸，头道麦汁 18–20%，全程保温约 78 °C |
| 酒糟可提取浸出物高 | 麦芽溶解差、粉太粗、糖化太短或不合适 | 调细粉碎，延长或强化糖化，稠醪煮得更久 |

**自测**

<details><summary>头道麦汁浓度越高，为什么收率反而越高？</summary>

头道麦汁量少了，就能留出更多洗糟水去冲洗酒糟，残留在糟里的浸出物更少。

</details>

<details><summary>能不能用 100 °C 过滤来加快速度？</summary>

不能。高温虽降低黏度，但会让 α-淀粉酶失活，洗糟中溶出的残余淀粉无法后糖化，造成“蓝醪”和淀粉浑浊。

</details>

## 3.5 麦汁煮沸与加酒花（Wort boiling, hop addition）

*Kunze p.281–323*

**目的**：溶解并异构化酒花苦味物，让蛋白与多酚凝固，灭菌并破坏全部酶，蒸发水分和 DMS 等不良挥发物，同时把热负荷压到最低。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 煮沸时间 | 传统 50–60 min；现代系统 40–50 min（有的 35–40 min） |
| 总蒸发 | 现代目标约 4–6%（过去 10–15%） |
| 低压煮沸 | 102–104 °C，最大过压约 0.5 bar |
| 定型麦汁 pH | 未酸化约 5.4–5.5；宜在煮沸末生物酸化到 5.1–5.2 |
| 可凝固氮 | 冷麦汁宜 20–30 mg/L（至少 14 mg/L） |
| 游离 DMS | 宜 40–60 µg/L 以下，冷却中点不超过 100 µg/L |
| 热负荷 TBI | 定型麦汁 &lt;45（宜 30–40）；冷麦汁 &lt;60 |
| MgSO₄ 可沉淀氮 | 约 200 mg/L；越高泡沫越好 |
| α-酸异构化所需时间 | 100 °C 约 90 min；130 °C 3–5 min；140 °C 2–3 min |
| 能耗 | 常规煮沸（蒸发 12%）约 14 kWh/hl 定型麦汁；低压煮沸约 9 kWh/hl |

**机理与要点**

- 苦味去向：煮沸中只有约 1/3 的 α-酸异构化；之后凝固物、酵母和泡沫还会带走一部分，最终按成品约 25–35% 留在啤酒里。
- pH 较高时异构化更好；pH 较低时苦味更细腻、色度升得少、蛋白凝固更好（最适约 pH 5.2）。
- 如今不追求把可凝固蛋白全部沉淀，而是保留一部分高分子蛋白给泡沫，所以煮沸时间和强度都在下降。
- DMS：前体 SMM 受热裂解成游离 DMS，随蒸汽排出；回旋静置中前体还在裂解 → 回旋前预冷到 85–90 °C 以下，或回旋后用汽提、闪蒸再除一次。
- 内加热器（锅内管束 + 分配伞）结构简单、易于 CIP；外加热器（每小时循环 7–8 次）控温精确、可用很低的蒸汽压。动态低压、分级香气煮沸、薄膜蒸发、真空闪蒸、汽提塔等现代系统的共同目标：低能耗、短时温和、低热负荷、保留泡沫蛋白。
- 锅汽冷凝器回收汽化热：每蒸发 1 hl 约得 0.8 hl 80 °C 热水；配合蓄能罐，可把下一批 72–74 °C 的麦汁预热到 93 °C 以上。
- 加酒花：多个品种时苦型先加，尽量异构化并赶走月桂烯等粗糙挥发物；香型最后加，甚至加在降到约 80 °C 的回旋槽里。

**相关工具**：[计算：酒花添加量](tools.md#hops)

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| DMS 高（煮蔬菜味） | 麦芽前体高、蒸发不足、回旋静置太久太热 | 保证蒸发效率；回旋前预冷或回旋后汽提 |
| TBI 高、色深 | 长时间强烈煮沸、回旋久 | 缩短煮沸、降低强度、回旋前预冷 |
| 热凝固物差 | 煮沸不足、pH 偏高、麦汁浑 | 酸化到 pH 5.2，保证剧烈沸腾，提高过滤清亮度 |

**自测**

<details><summary>现代煮沸更短更温和，为什么不担心 DMS？</summary>

靠结构给麦汁足够的蒸发界面（分配伞、薄膜、闪蒸、汽提）把 DMS 带走，同时避免长时间强热带来的 TBI、色度上升和泡沫蛋白过度沉淀。

</details>

<details><summary>为什么锅汽要冷凝回收，而不是直接排掉？</summary>

一方面回收大量汽化热得到热水，另一方面排出的蒸汽气味会扰民（德国受排放法规约束）；冷凝水含 DMS 等物质，不宜作酿造水，但可用于预冲洗等。

</details>

<a id="s3-6"></a>

## 3.6 糖化间收率（Brewhouse yield）

*Kunze p.323–331*

**目的**：用定型麦汁的量和浓度，算出投料中有多少变成了浸出物；这是糖化间效率的核心指标，也是税务核查的依据。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 公式 | 收率 = 浸出物(kg/hl) × 0.96 × 热定型麦汁(hl) ÷ 投料(dt) |
| 0.96 | 热麦汁（约 100 °C）冷到 20 °C 的体积收缩系数 |
| 收率因子 | 浸出物 × 比重 × 0.96，已并入 Plato 表（例如 12.0% 对应 12.06） |
| 正常范围 | 74–79%；最多比细粉、风干基的实验室收率低约 1% |
| 比重计 | 20 °C 校准，读最上方仍清楚的刻度；不在 20 °C 时查修正值 |

**机理与要点**

- 实验室收率与糖化间收率之差是评价设备和操作的标尺；现代糖化间这个差很小。
- 影响因素：麦芽（溶解度；投料按风干基记，水分越高收率越低）、设备、糖化法（稠醪煮得越久浸出越多）、过滤（分次洗糟、出流均匀）、操作纪律。
- 回收的浑浊麦汁回到下一批时，计算下一批收率要扣掉其体积的 75%，避免重复计算。

**相关工具**：[计算：糖化间收率与发酵间收率](tools.md#yield)

**自测**

<details><summary>为什么要乘 0.96？</summary>

定型麦汁在接近 100 °C 下量取，比重计却在 20 °C 读数；冷却时体积收缩约 4%（这 4% 里还包括酒花糟和凝固物），不乘就会高估浸出物。

</details>

<a id="s3-7"></a>

## 3.7 回旋沉淀与热凝固物（Whirlpool, hot break）

*Kunze p.336–346*

**目的**：去除 30–80 µm 的热凝固物（粗凝固物）。它妨碍澄清、包裹酵母、增加损失，还带入麦芽脂肪酸。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 热凝固物 | 定型后 6,000–8,000 mg/L，去除后应 ≤100 mg/L |
| 回旋槽 | 平底，向出口有 1% 坡度；直径与液高常取 3 : 1（1 : 1 到 5 : 1） |
| 进口 | 流速 ≤3.5 m/s，大流量、低剪切，切向进入（底部一个防吸氧，下 1/3 一个产生旋转） |
| 静置 | 20–30 min；加 Denk 环可缩短 30–60%，但不少于 20 min |
| Imhoff 锥测试 | 适合回旋的麦汁 5–6 min 沉降完，上层清亮 |
| 分离机 | 损失 &lt;0.3%，但碟片驱动 0.65–0.8 kW/m³、投资高 |
| 整酒花 | 每 kg 酒花约带走 4.9 L 麦汁（喷淋加压榨可降到 2.0 L） |

**机理与要点**

- “茶杯效应”：旋转停下后，底部边界层因摩擦减速，压力与离心力失衡，形成指向中心的二次流，把颗粒推到中央堆成锥。
- 底部的环形涡会干扰沉降，Denk 环（离底一定高度的同心格栅）可以切断它。
- 为降低热负荷和后生成的 DMS，现代工艺尽量缩短回旋静置，并在回旋前预冷到 85 °C 以下。
- 浑浊麦汁（约 75% 麦汁 + 25% 凝固物）在下一批洗糟开始时加回，几乎可全部回收。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 凝固物锥不紧、带进冷麦汁 | 过滤浑、管道剪切大、进液太快、二次流强、出液太快、液高与直径比例不当 | 逐项检查进液条件；出液末期放慢速度 |

**自测**

<details><summary>回旋槽底部为什么不宜做中心凝固物杯？</summary>

凹坑破坏底部边界层、削弱回旋效应，也不能防止锥体露出液面后坍塌。

</details>

<a id="s3-8"></a>

## 3.8 冷却、充氧与冷凝固物（Cooling, aeration, cold break）

*Kunze p.347–357*

**目的**：快速把麦汁冷到接种温度，按需去除冷凝固物，并给酵母供足氧。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 冷却 | 板式换热器，从 95–98 °C 冷到 5–8 °C |
| 一段冷却 | 1–2 °C 冰水被加热到 80–88 °C；两段冷却先用工艺水预冷，再用冰水 |
| 板片压差 | 通常约 2 bar，最多 4 bar |
| 冷凝固物 | 约 0.5 µm，60 °C 以下开始析出；冷到 5 °C 仍有约 14% 溶解 |
| 残留冷凝固物 | 120–160 mg/L（干物质）较理想 |
| 充氧目标 | 8–10 mg O₂/L；理论上每 hl 只需约 3 L 空气，实际要多得多 |
| 氧的溶解系数 | 0 °C 47.4，10 °C 36.8，20 °C 30.0 mL/(kg·bar) |

**机理与要点**

- 冷麦汁充氧是整个啤酒生产中唯一有意加氧的时刻：几小时内被酵母用于合成不饱和脂肪酸和甾醇，并不伤麦汁。热麦汁充氧则会大量氧化，使麦汁变深变苦。
- 空气必须先经无菌过滤；充氧方式有烧结烛管、文丘里管、双组分喷嘴、静态混合器、离心混合器。
- 冷凝固物是蛋白-多酚复合物，不宜完全去除，否则口味发空；方法有珍珠岩过滤（约 90%）、浮选（4–8 h，去除 60–65%，已少新建）、冷麦汁分离机（50% 以上）。
- 如果热凝固物去得干净、酵母活力强，如今多数厂不再单独去除冷凝固物。

**自测**

<details><summary>为什么说要“给酵母供氧，而不是给麦汁供氧”？</summary>

氧对麦汁本身只有坏处（氧化）；它唯一的价值是让酵母在起酵的几小时里合成细胞膜成分。理想情况是氧直接到达酵母、很快被用完。

</details>
