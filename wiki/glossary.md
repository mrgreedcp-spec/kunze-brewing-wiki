# 术语表

| 术语 | 英文 | 解释 | 见 |
| --- | --- | --- | --- |
| 巴氏杀菌单位（PU） | Pasteurisation unit | 60 °C 保持 1 min 的杀菌效果为 1 PU；温度每升 1 °C，效果约乘 1.393。 | [5.3 生物稳定化](05-filtration-stabilisation.md#s5-3) |
| 骠骑兵 | Hussar | 叶芽长过粒长的麦粒，说明发芽温度过高或发芽过度。 | [2.4 发芽](02-malting.md#s2-4) |
| 表观发酵度 | Apparent attenuation | 用比重计读数计算的发酵程度；真实发酵度约为表观值的 0.81 倍。 | [4.4 常规发酵与贮酒](04-fermentation.md#s4-4) |
| 残碱度 | Residual alkalinity | 碳酸盐硬度与钙镁降低 pH 作用之差，决定醪的 pH；比尔森类不超过约 2 °dH。 | [1.3 水](01-raw-materials.md#s1-3) |
| 残糖水 | Last runnings | 洗糟最后流出的低浓度麦汁（约 2%），再洗已不经济。 | [3.4 过滤](03-wort-production.md#s3-4) |
| 穿透点 | Break point | 焙焦中料层整体干透、排气湿度明显下降的时刻，标志预干结束，之后可减风升温。 | [2.5 焙焦](02-malting.md#s2-5) |
| 纯酒令 | Reinheitsgebot | 德国啤酒只允许使用麦芽、酒花、水和酵母的规定；书中多处据此区分允许的工艺和添加物。 | [1.5 辅料](01-raw-materials.md#s1-5) |
| 脆度 | Friability | 用脆度计测得的麦芽松脆程度，&gt;85% 说明细胞溶解良好。 | [2.7 麦芽评价](02-malting.md#s2-7) |
| 错流过滤 | Cross-flow filtration | 液体沿膜面流过、只有一部分清液透过膜的过滤方式，可以不用硅藻土。 | [5.2 精滤、错流与无硅藻土过滤](05-filtration-stabilisation.md#s5-2) |
| 等压灌装 | Counter-pressure filling | 先让瓶内建立与贮液缸相同的气压，再让啤酒平稳流入，防止 CO₂ 析出。 | [6.2 灌装与压盖](06-filling-cleaning.md#s6-2) |
| 碘正常 | Iodine normality | 冷却的醪样遇碘液不再变蓝或变红，说明淀粉已分解成糖和小糊精。 | [3.2 糖化](03-wort-production.md#s3-2) |
| 凋萎 | Withering | 焙焦前段用低温大风量缓慢除水的阶段，保护酶并防止玻璃质。 | [2.5 焙焦](02-malting.md#s2-5) |
| 调湿粉碎 | Conditioned milling | 粉碎前短时间润湿谷皮，让谷皮有弹性不易碎，以保护滤层、提高收率。 | [3.1 粉碎](03-wort-production.md#s3-1) |
| 定型麦汁 | Cast wort | 煮沸结束、泵出煮沸锅时的麦汁；煮沸开始时的称满锅麦汁。 | [3.5 麦汁煮沸与加酒花](03-wort-production.md#s3-5) |
| 二甲基硫（DMS） | Dimethyl sulphide | 有煮蔬菜味的挥发性硫化物，阈值约 0.10 mg/L，冷麦汁中游离 DMS 宜低于 100 µg/L。 | [3.5 麦汁煮沸与加酒花](03-wort-production.md#s3-5) |
| 发酵度极限 | Attenuation limit | 全部可发酵物质都发酵后能达到的最高表观发酵度，淡色全麦啤酒约 80–84%。 | [4.4 常规发酵与贮酒](04-fermentation.md#s4-4) |
| 高浓酿造 | High gravity brewing | 用较高浓度的麦汁生产，之后再加水稀释到目标浓度，以提高产能、节省能源。 | [5.6 特殊工艺](05-filtration-stabilisation.md#s5-6) |
| 高压喷射（HDE） | High pressure jetting | 向刚灌好的瓶口射入极细的热水，使瓶颈起泡、把空气顶出。 | [6.2 灌装与压盖](06-filling-cleaning.md#s6-2) |
| 硅胶 | Silica gel | 吸附形成浑浊的多肽的稳定剂，对泡沫蛋白影响小。 | [5.4 胶体稳定化](05-filtration-stabilisation.md#s5-4) |
| 硅藻土 | Kieselguhr | 硅藻化石粉，啤酒预涂过滤最常用的助滤剂；粉尘可致矽肺。 | [5.1 硅藻土过滤](05-filtration-stabilisation.md#s5-1) |
| 合葎草酮 | Cohumulone | α-酸的一种组分，苦味较粗；优质香型酒花中占比低于 20%。 | [1.2 酒花](01-raw-materials.md#s1-2) |
| 回旋沉淀槽 | Whirlpool | 切向进料的平底圆筒容器，利用“茶杯效应”把热凝固物聚成中心锥。 | [3.7 回旋沉淀与热凝固物](03-wort-production.md#s3-7) |
| 界限糊精 | Limit dextrins | 含 1,6 支点、两种淀粉酶都切不动的糊精，不能被酵母发酵。 | [3.2 糖化](03-wort-production.md#s3-2) |
| 浸出法 | Infusion mashing | 全醪在一个容器里按程序升温、各温度休止的糖化方法。 | [3.2 糖化](03-wort-production.md#s3-2) |
| 浸麦度 | Degree of steeping | 浸麦结束（或发芽中）籽粒的含水量。淡色麦芽 42–44%，深色 44–47%。 | [2.3 浸麦](02-malting.md#s2-3) |
| 就地清洗（CIP） | Cleaning in place | 不拆设备，用管路循环清洗液、按程序清洗和消毒。 | [6.5 清洗与消毒（CIP）](06-filling-cleaning.md#s6-5) |
| 苦味单位（BU） | Bitterness units | 每升啤酒中苦味物的毫克数。 | [3.5 麦汁煮沸与加酒花](03-wort-production.md#s3-5) |
| 库尔巴哈指数 | Kolbach index | 可溶氮占总氮的百分比，衡量蛋白溶解程度，38–42% 为宜。 | [2.7 麦芽评价](02-malting.md#s2-7) |
| 老化羰基 | Ageing carbonyls | 灌装后逐渐增加、阈值极低的醛类，造成纸板味、面包味等老化风味。 | [5.5 风味稳定与防氧](05-filtration-stabilisation.md#s5-5) |
| 类黑精 | Melanoidins | 美拉德反应生成的红褐色物质，带来颜色、麦香和还原力。 | [2.5 焙焦](02-malting.md#s2-5) |
| 冷浑浊 | Chill haze | 啤酒冷却时出现、回温到 20 °C 又溶解的胶体浑浊，随时间转为永久浑浊。 | [5.4 胶体稳定化](05-filtration-stabilisation.md#s5-4) |
| 冷凝固物 | Cold break | 麦汁冷到约 60 °C 以下析出的约 0.5 µm 细颗粒，不宜完全去除。 | [3.8 冷却、充氧与冷凝固物](03-wort-production.md#s3-8) |
| 麦芽单耗 | Malt usage | 每 hl 可售啤酒消耗的麦芽公斤数，11% 啤酒约 17 kg/hl。 | [6.4 损耗、麦芽单耗与产能](06-filling-cleaning.md#s6-4) |
| 美拉德反应 | Maillard reaction | 糖与氨基酸在加热下生成色素和香气物质的反应，同时产生日后老化味的前体。 | [2.5 焙焦](02-malting.md#s2-5) |
| 啤酒损耗 | Beer loss | 定型麦汁量与可售啤酒量之差占定型麦汁的百分比，平均 8–10%。 | [6.4 损耗、麦芽单耗与产能](06-filling-cleaning.md#s6-4) |
| 起泡酒 | Kräusen | 处于低泡期（发酵度约 25%）的嫩啤酒；加入正在成熟的啤酒中可促进后发酵和双乙酰还原。 | [4.4 常规发酵与贮酒](04-fermentation.md#s4-4) |
| 热负荷（TBA / TBI） | Thiobarbituric acid index | 衡量麦芽或麦汁受热程度的指标，越高说明美拉德产物越多、风味稳定性越差。麦芽 &lt;14，定型麦汁 &lt;45。 | [2.5 焙焦](02-malting.md#s2-5) |
| 热凝固物 | Hot break | 煮沸中凝固析出的蛋白-多酚颗粒，30–80 µm，在回旋槽中去除。 | [3.7 回旋沉淀与热凝固物](03-wort-production.md#s3-7) |
| 日光臭 | Light-struck flavour | 350–500 nm 的光使异 α-酸侧链裂解成硫醇产生的臭味；棕瓶防护最好。 | [5.5 风味稳定与防氧](05-filtration-stabilisation.md#s5-5) |
| 溶解 | Modification | 发芽中酶把胚乳的细胞壁和蛋白基质分解开，使胚乳变得松脆、可被糖化；分细胞溶解和蛋白溶解。 | [2.4 发芽](02-malting.md#s2-4) |
| 生物酸化 | Biological acidification | 培养麦芽自带的乳酸菌得到乳酸液，用来降低醪和麦汁的 pH；纯酒令下唯一合规的降 pH 方法。 | [3.2 糖化](03-wort-production.md#s3-2) |
| 收率因子 | Yield factor | 浸出物 × 20/4 °C 比重 × 0.96；乘以热定型量就得到浸出物公斤数。 | [3.6 糖化间收率](03-wort-production.md#s3-6) |
| 双乙酰 | Diacetyl | 有黄油味的嫩啤酒味物质，与戊二酮合称连二酮；成品总双乙酰应 ≤0.10 mg/L，是判断成熟的指标。 | [4.2 副产物与成熟](04-fermentation.md#s4-2) |
| 瞬时杀菌 | Flash pasteurisation | 灌装前用板式换热器把啤酒加热到 68–72 °C 保持约 50 s 再冷却。 | [5.3 生物稳定化](05-filtration-stabilisation.md#s5-3) |
| 糖化间收率 | Brewhouse yield | 投料中作为浸出物进入定型麦汁的百分比，正常 74–79%。 | [3.6 糖化间收率](03-wort-production.md#s3-6) |
| 糖化力 | Diastatic power | 麦芽淀粉酶的总活力，以 WK 单位表示，淡色麦芽约 240–260 WK。 | [2.7 麦芽评价](02-malting.md#s2-7) |
| 跳跃糖化 | Jump mashing | 向约 35 °C 的稠醪注入沸水直接升到约 72 °C，跳过 β-淀粉酶，得到低发酵度麦汁。 | [3.3 辅料糖化与特殊糖化法](03-wort-production.md#s3-3) |
| 同化法 | Assimilation process | 在同化器里让酵母持续保持对数期、边抽边补的扩培方法。 | [4.3 纯种酵母扩培](04-fermentation.md#s4-3) |
| 头道麦汁 | First wort | 过滤时最先从酒糟中流出、未经稀释的麦汁，浓度比定型麦汁高 4–6%。 | [3.4 过滤](03-wort-production.md#s3-4) |
| 投料 | Mashing-in | 把粉与水按预定比例和温度混合，糖化从此开始。 | [3.2 糖化](03-wort-production.md#s3-2) |
| 洗糟 | Sparging | 用热水把酒糟里残留的浸出物洗出来，流出的称二道麦汁。 | [3.4 过滤](03-wort-production.md#s3-4) |
| 细胞溶解 | Cytolysis | 细胞壁中 β-葡聚糖和戊聚糖的分解。只能在麦芽厂充分完成，酒厂只能部分弥补。 | [2.4 发芽](02-malting.md#s2-4) |
| 协定糖化法 | Congress mash | 麦芽分析用的标准实验室糖化程序，浸出率、色度、黏度等都以它为基础测定。 | [2.7 麦芽评价](02-malting.md#s2-7) |
| 休止 | Rest | 在某种酶的最适温度保持一段时间，让它充分作用。 | [3.2 糖化](03-wort-production.md#s3-2) |
| 一罐法 | One-tank process | 发酵、成熟和冷贮都在同一个锥形罐里完成，不转罐。 | [4.5 锥形罐发酵与成熟](04-fermentation.md#s4-5) |
| 异 α-酸 | Iso-α-acids | α-酸在煮沸中异构化的产物，易溶、很苦，是啤酒苦味的主要来源。 | [1.2 酒花](01-raw-materials.md#s1-2) |
| 游离氨基氮（FAN） | Free amino nitrogen | 麦汁中酵母可以利用的氨基态氮，12% 麦汁约需 200–230 mg/L。 | [4.1 酵母代谢](04-fermentation.md#s4-1) |
| 预涂 | Precoat | 过滤开始前在支撑网或滤板上涂出的硅藻土层，负责截留最细的颗粒。 | [5.1 硅藻土过滤](05-filtration-stabilisation.md#s5-1) |
| 脂氧合酶（LOX） | Lipoxygenase | 把不饱和脂肪酸氧化的酶，是老化味的来源之一；在低温、较高 pH 的投料阶段最活跃。 | [3.2 糖化](03-wort-production.md#s3-2) |
| 煮出法 | Decoction mashing | 取出一部分稠醪煮沸再泵回，用来提升全醪温度的糖化方法，分一次、两次、三次煮出。 | [3.2 糖化](03-wort-production.md#s3-2) |
| 转罐 | Transfer | 把嫩啤酒从发酵容器转入贮酒容器；此时仍应留约 1% 可发酵浸出物。 | [4.4 常规发酵与贮酒](04-fermentation.md#s4-4) |
| 锥形罐（CCV） | Cylindroconical vessel | 上部圆柱、下部锥形的大型密闭罐，用于发酵、成熟和冷贮。 | [4.5 锥形罐发酵与成熟](04-fermentation.md#s4-5) |
| 自溶 | Autolysis | 酵母细胞被自身的酶分解，内容物进入啤酒，pH 升高、风味和泡沫变差。 | [4.2 副产物与成熟](04-fermentation.md#s4-2) |
| Crabtree 效应 | Crabtree effect | 糖浓度超过约 0.1 g/L 时，即使有氧，酵母的呼吸也被抑制而进行发酵。 | [4.1 酵母代谢](04-fermentation.md#s4-1) |
| DMS 前体（SMM） | S-methylmethionine | 发芽中形成的无味前体，受热裂解成 DMS；焙焦和煮沸都要把它转化并赶走。 | [2.5 焙焦](02-malting.md#s2-5) |
| PVPP | Polyvinylpolypyrrolidone | 不溶的交联聚合物，选择性吸附多酚以提高胶体稳定性，可用热碱再生。 | [5.4 胶体稳定化](05-filtration-stabilisation.md#s5-4) |
