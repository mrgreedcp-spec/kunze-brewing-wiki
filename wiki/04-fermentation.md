# 04 发酵与成熟（Fermentation and maturation）

> Kunze 原书印刷页 p.367–452 · [返回首页](README.md)

酵母把可发酵糖变成酒精和 CO₂，同时生成并再去除一批副产物。判断成熟的指标是双乙酰；最后在 −1 至 −2 °C 冷贮至少一周，为过滤和胶体稳定做准备。

- **输入**：接种麦汁 + 酵母
- **输出**：成熟啤酒：−1 °C，双乙酰 ≤0.10 mg/L，溶氧约 0
- **关键数字**：接种 20–30×10⁶/mL · 双乙酰 ≤0.10 mg/L · 17–20 d

**本页工序**：[4.1 酵母代谢](#s4-1) · [4.2 副产物与成熟](#s4-2) · [4.3 纯种酵母扩培](#s4-3) · [4.4 常规发酵与贮酒](#s4-4) · [4.5 锥形罐发酵与成熟](#s4-5) · [4.6 酵母回收、罐底啤酒与 CO₂](#s4-6) · [4.7 放酒前的啤酒](#s4-7)

## 4.1 酵母代谢（Yeast metabolism）

*Kunze p.367–375*

**目的**：理解酵母为什么这样做：它要的是能量和建造细胞的材料，酒精和 CO₂ 是它要排掉的废物。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 总反应 | C₆H₁₂O₆ → 2 C₂H₅OH + 2 CO₂（ΔG 约 −230 kJ/mol） |
| 质量比 | 180 g 葡萄糖 → 92 g 乙醇 + 88 g CO₂ |
| 能量去向 | 只有 2 ATP（约 61 kJ）被酵母利用，约 169 kJ 成为热 → 全麦啤酒约 4,500–4,700 kJ/hl |
| 糖的利用顺序 | 葡萄糖、果糖 → 蔗糖、麦芽糖 → 麦芽三糖（下面酵母要到后发酵才利用） |
| 发酵与呼吸 | 约 98% 的糖被发酵，约 2% 被呼吸 |
| FAN 标尺 | 200–230 mg/L（12% 麦汁）；脯氨酸几乎不能利用 |
| 锌 | 0.10–0.15 mg/L；低于约 0.12 mg/L 易出现发酵问题 |
| 硝酸盐 | 20 mg/L 就对酵母有害（被还原成亚硝酸盐） |

**机理与要点**

- 糖酵解用 10 步把葡萄糖变成 2 个丙酮酸；无氧时丙酮酸脱羧成乙醛，再由乙醇脱氢酶（需要锌）还原成乙醇。
- 巴斯德效应：有氧时发酵受抑；Crabtree 效应：糖浓度超过约 0.1 g/L 时，即使有氧，呼吸也被抑制——所以麦汁里的酵母总在发酵。
- 氨基酸经脱氨、脱羧、还原变成高级醇（Ehrlich 途径）；脱氨留下的有机酸进入啤酒。
- 起酵前酵母先动用糖原（最初 10–12 h 大幅下降），之后再积累到干物质的约 30%；冷藏能保住糖原，也就保住了下一代的起酵能力。
- 酵母蛋白酶 A 会分解大麦来的泡沫蛋白 LTP1，冷除菌灌装的啤酒尤其受影响。

**自测**

<details><summary>为什么发酵放出的热远大于酵母“用到”的能量？</summary>

每 mol 葡萄糖释放约 230 kJ，只有 2 个 ATP（约 61 kJ）被酵母捕获，其余约 169 kJ 以热的形式放出，必须由冷却系统带走。

</details>

<details><summary>为什么加糖或大量辅料的麦汁更容易出发酵问题？</summary>

它们不带来氨基酸、磷酸盐和锌，而酵母建造新细胞离不开这些物质。

</details>

## 4.2 副产物与成熟（By-products, maturation）

*Kunze p.375–386*

**目的**：区分会被去除的“嫩啤酒味”和去不掉的“成熟香气”，用工艺把两者都控制在目标范围。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 嫩啤酒味 | 双乙酰、醛、硫化物：成熟中可被生化去除 |
| 成熟香气 | 高级醇、酯：常规工艺去不掉，只能在发酵中控制生成量 |
| 双乙酰 | 风味阈值约 0.10–0.15 mg/L；成品总双乙酰（含前体）≤0.10 mg/L |
| 乙醛 | 嫩啤酒 20–40 mg/L → 成品 &lt;8–10 mg/L |
| 高级醇 | 淡色全麦啤酒 60–90 mg/L；&gt;100 mg/L 损害风味 |
| 酯 | 下面发酵 ≤60 mg/L，上面发酵 ≤80 mg/L；重要的约 6 种，如乙酸乙酯、乙酸异戊酯 |
| pH | 接种麦汁 5.3–5.6（生物酸化 5.0–5.3）→ 啤酒 4.3–4.6，目标 4.2–4.4 |
| CO₂ | 活泼的啤酒 0.45–0.50%；发酵产生的 CO₂ 只有约 15% 留在酒里 |
| 色度 | 发酵头几天约变浅 3 EBC |

**机理与要点**

- 双乙酰分三步：酵母排出无味的乙酰羟基酸（前体）→ 前体在细胞外经氧化脱羧变成双乙酰（低 pH、升温、进氧都会加快；这一步限制了成熟速度）→ 只有酵母能把双乙酰还原成乙偶姻和丁二醇。酵母的还原能力约为生成速度的 10 倍，并随温度大幅提高。
- 每次吸氧（比如转罐）都会让残留前体更多地转成双乙酰，又得等酵母再还原一次。
- 加快成熟：发酵到接近最终发酵度、低 pH、接种后杜绝进氧、较高的成熟温度（下面发酵啤酒最高约 18 °C）、让足量活跃酵母保持悬浮、加起泡酒。
- 高级醇约 80% 在主发酵中生成：温度高、搅动、氨基酸不足、麦汁浓度超过 13%、接种温度高于 8 °C 都会增加；提高接种量、冷接种冷发酵、尽早施压则减少。
- 酯：麦汁越浓越多；温度高、搅动多会增加；施压会减少；罐越高（静压和 CO₂ 越高）越少。
- 自溶的信号是 pH 升高：酵母味、苦味变宽、泡沫和稳定性下降、双乙酰去除变差、更容易感染。

**自测**

<details><summary>为什么用双乙酰判断成熟，而不是看酯？</summary>

双乙酰的去除与其他嫩啤酒味大致同步，而且能测；它低于阈值时，醛和硫化物通常也已消失。酯属于成熟香气，本来就不会被去掉。

</details>

<details><summary>转罐时吸了一点氧，为什么双乙酰会“回升”？</summary>

氧加快了残留前体向双乙酰的转化，新生成的双乙酰需要酵母再花时间还原。

</details>

## 4.3 纯种酵母扩培（Pure yeast propagation）

*Kunze p.386–395*

**目的**：在无菌条件下，用最短的时间提供代谢正确、活力高的接种酵母。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 分离 | Lindner 滴培养挑选单细胞，8–10 °C 培养；斜面 0–5 °C 可保存 6–9 个月 |
| 实验室放大 | 每步约 1 : 10（10 mL → 100 mL → 1 L），再到 Carlsberg 瓶（8–10 L、20–25 L） |
| 扩培终点 | 约 1–1.4 亿个/mL（受氨基酸等营养限制） |
| 接种麦汁要求 | 碘正常；溶氧 ≥8–10 mg/L；FAN 200–230 mg/L；锌 ≥0.15 mg/L；pH 5.0–5.2；黏度 ≤1.7 mPa·s（10%） |
| 接种酵母要求 | 死细胞 ≤3%，无杂酵母和杂菌，浓稠泥状 |
| 放大倍数 | 待接种麦汁 : 旺盛发酵的种液 不超过 3 : 1 到 4 : 1 |
| 同化法 | 同化器保持对数期（约 1 亿个/mL、表观浸出物 6–7%），抽走 80–85% 去接种，留 15–20% 再补麦汁 |

**机理与要点**

- 扩培用定型麦汁（酒花苦味物能抑制杂菌），100 °C 灭菌至少 30 min 后冷到 14–16 °C。
- 酵母在 20–25 °C 繁殖得快，但扩培中要逐步把它带到酒厂的发酵温度，避免冷冲击。
- 补料（Drauflassen）让酵母始终处在对数期：起酵快、pH 降得快、双乙酰去除更快、口味更干净。
- 单罐法每一代都重新接种纯培养，排除了退化；第一天每 15 min 充气 1 min，第二天每 5 min 充气 1 min。
- 小厂可用开放式扩培（两级敞口容器或奶桶法），但无法保证无菌。

**自测**

<details><summary>扩培时为什么不能靠“拼命充氧”无限加快？</summary>

麦汁中的糖会抑制呼吸（Crabtree 效应）；而且增殖到约 1 亿个/mL 时，氨基酸等营养就不够了。

</details>

## 4.4 常规发酵与贮酒（Conventional fermentation, lagering）

*Kunze p.395–416*

**目的**：在开放发酵池完成主发酵，再在密闭贮酒罐里加压后发酵，让啤酒饱和 CO₂ 并澄清。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 接种量 | 20–30×10⁶ 个/mL ≈ 每 hl 0.6–1 L 浓酵母泥（泥约 3×10⁹ 个/mL） |
| 接种温度 | 5–7 °C |
| 最高温度 | 冷发酵 8–9 °C；暖发酵 10–15 °C |
| 降温 | 每天不超过 1 K；转罐时约 4–5 °C |
| 主发酵 | 6–8 天；发酵热约 587 kJ/kg 浸出物 |
| 转罐时浸出物 | 全麦啤酒约 3.4–4%（表观发酵度约 66–69%），最后 24 h 只降 0.2–0.3% |
| 转罐与极限之差 | 约 10 个百分点（约留 1% 浸出物给后发酵） |
| 发酵度极限 | 淡色全麦和比尔森约 80–84% |
| 真实发酵度 | ≈ 0.81 × 表观发酵度（Balling） |
| 收获酵母 | 每 hl 接种麦汁 2.0–2.5 L 浓酵母 |
| 贮酒 | −2 至 −1 °C 至少 7 天；灌装时 CO₂ 要 &gt;0.50%，0.32% 已显平淡 |
| 发酵间 | 室温 5.5–6 °C；CO₂ 浓度 4% 就可能致命 |

**机理与要点**

- 发酵外观依次是：变白 → 低泡 → 高泡 → 泡沫塌落 → 松散的褐色盖层（转罐前撇除，以免沉下去弄脏酵母）。
- 表观发酵度用比重计直接测，被酒精“骗”了一部分，但与真实值成比例，所以实践中通用。
- 浑浊转罐（带较多酵母）适合低发酵度酵母、贮酒时间短、窖冷、罐大；清亮转罐则相反。
- 调配可以用混合十字或混合方程计算；两种液体其实很难真正混匀。
- 按亨利定律，CO₂ 溶解量与罐内绝对压力成正比、温度越低越多；用调压阀设定压力（过去用水柱、汞柱）。后发酵放出的 CO₂ 还能“气洗”带走部分挥发性嫩啤酒味。
- 冷凝固物颗粒很小，贮酒越冷析出越多；灭菌木片增加表面积，可以加快澄清。

**相关工具**：[计算：接种量](tools.md#pitch) · [计算：表观与真实发酵度](tools.md#atten) · [计算：调配（混合十字）](tools.md#blend) · [计算：CO₂ 溶解量](tools.md#co2)

**自测**

<details><summary>转罐时为什么故意留约 1% 的可发酵浸出物？</summary>

这些糖在密闭加压的贮酒罐里后发酵，产生的 CO₂ 让啤酒饱和，同时把部分挥发性嫩啤酒味气洗出去。

</details>

<details><summary>表观发酵度 80% 时，真实发酵度大约多少？</summary>

约 0.81 × 80% ≈ 65%。

</details>

## 4.5 锥形罐发酵与成熟（Cylindroconical vessels）

*Kunze p.416–443*

**目的**：在一个或两个大型密闭锥形罐里完成发酵、成熟和冷贮；用仪表和冷却程序代替过去的“看”和“闻”。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 液高 | 发酵罐最大约 20 m；直径与总液高约 1 : 2 |
| 锥角 | 60–90°，常用 60–75°；60° 时锥高 ≈ 0.866 × 直径 |
| 顶空 | 发酵罐 ≥18–25%；小麦啤酒约 40%（只装一半）；贮酒罐 5–25%（视是否仍在还原双乙酰、是否加起泡酒） |
| 罐容量 | 一般只接收半天的糖化间产量 |
| 内表面 | Ra &lt;0.8 µm；锥底抛光到约 0.25 µm |
| 冷却需求 | 共约 8,600–9,000 kJ/hl：发酵热 4,300–4,600 + 冷到 −1 °C 约 4,200 |
| 冷却面（每 100 hl） | 直接蒸发冷却的发酵罐约 1.6–3.4 m²（视蒸发温度） |
| 麦汁 FAN | 理想 ≥230 mg/L；全麦芽不低于 200，用辅料至少 150 |
| 周期 | 发酵、成熟加冷贮一般 17–20 天 |

**机理与要点**

- 从下灌、从下排；罐顶有超压阀、真空阀和 CIP 喷头，要纳入 CIP 并防冻；管路切换用带泄漏指示的双座阀。
- 真空比超压更危险：热罐被冷水喷淋时，气体收缩、蒸汽冷凝（体积缩到约 1/1786），大罐会瞬间被吸瘪。
- 冷贮时约 +2.5 °C 的啤酒密度最大、沉在锥部；啤酒约 −2 °C 开始结冰 → 锥部必须单独冷却，否则那里的酵母偏暖、自溶。
- 酵母尽早分次排出：成熟后期酵母排出蛋白酶 A 损害泡沫，锥部的 CO₂ 分压和缺乏营养让老细胞自溶。
- 一罐法省清洗、少 CO₂ 损失、不转罐也就不吸氧；两罐法必须在发酵罐里完成双乙酰还原，贮酒罐只做冷贮、澄清和口味圆润。
- 可以减少或不给最后一批麦汁充氧，以保持发酵活性，并促进酵母生成 SO₂（有利于风味稳定）。

**相关工具**：[数据：下面发酵温度程序](programmes.md#fermentation) · [计算：锥形罐容积与顶空](tools.md#ccv) · [计算：发酵与冷贮冷量](tools.md#cool)

**自测**

<details><summary>锥形罐为什么必须有锥部冷却？</summary>

冷贮时最重的 +2.5 °C 啤酒沉在锥部，没有锥部冷却那里就一直偏暖，沉在锥底的酵母会耗尽储备并自溶。

</details>

<details><summary>一罐法的主要缺点是什么？</summary>

为发酵泡沫预留的顶空在冷贮阶段闲置，罐容利用率较低。

</details>

## 4.6 酵母回收、罐底啤酒与 CO₂（Yeast cropping, recovery, CO₂）

*Kunze p.443–452*

**目的**：在酵母状态最好时收获、处理、贮存和回用；把罐底里的啤酒和发酵产生的 CO₂ 回收回来。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 回用前充氧 | 先排胞内 CO₂，充氧 2–3 h 后接种；不马上用就不要充氧 |
| 贮存温度 | 短期 ≤8 °C（接种温度）；过周末 3–5 °C；停酿期 0–1 °C |
| 死细胞 | 尽量 ≤3%，任何情况下 ≤5%（美蓝染色） |
| 回用代数 | 下面酵母一般不超过 5–6 代；上面酵母常 5–15 代 |
| 罐底 | 约为啤酒量的 1.5–2%；可回收约总产量的 1% |
| 罐底啤酒处理 | 每 hl 加 50 g 活性炭 + 50 g 硅胶，硅藻土过滤并瞬时杀菌后，最多 5% 兑入刚开始发酵的麦汁 |
| CO₂ 平衡 | 常规主发酵约产 4 kg/hl；酒厂自用约 1.8–2.0 kg/hl；锥形罐实际可回收约 2.0 kg/hl |
| CO₂ 纯度 | 应达 99.998%（99.97% 已不够） |

**机理与要点**

- 收酵母时要让酵母沿锥壁缓慢下滑、保持水平界面；排得太快会形成漏斗，把啤酒一起吸走。
- 10 m 液柱下酵母胞内约有 1 bar 过压，突然泄压会大量起泡 → 泵入带背压的容器，吹无菌空气排出 CO₂ 后再泄压。
- 酵母状态差的信号：初口感有硫味或酵母味、泡沫差、苦味宽而持久、啤酒 pH 升 0.1–0.2、发酵拖延、双乙酰高、死细胞增多、絮凝变差、过滤困难。
- 过去洗酵母、过筛、水下保存的做法因污染风险和营养流失已被淘汰，改为保存在发酵后的啤酒残液中。
- CO₂ 回收流程：泡沫分离 → 气柜缓冲 → 洗涤 → 两级压缩到 18–22 bar → 冷却 → 交替干燥 → 活性炭 → 液化 → 储罐。

**自测**

<details><summary>收获的酵母如果不立刻接种，为什么不应充氧？</summary>

充氧会让它开始呼吸和合成，但没有麦汁提供新能源，只能消耗自己的糖原储备；下一代起酵变慢，死细胞增多。

</details>

## 4.7 放酒前的啤酒（Beer quality on drawing off）

*Kunze p.447*

**目的**：成熟啤酒离开贮酒罐去过滤之前，应当已经在胶体上稳定，并满足下面这组数字。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 温度 | 0 至 −1 °C（在 −1 至 −2 °C 冷贮一周之后） |
| CO₂ | 不补充碳酸化也至少 0.50% |
| pH | 4.2–4.4，最高 4.6 |
| 酵母浓度 | 1–2×10⁶ 个/mL，最多 5×10⁶ 个/mL |
| 双乙酰 | ≤0.10 mg/L |
| 溶解氧 | 0 mg/L |

**自测**

<details><summary>为什么过滤前的溶氧应当是 0？</summary>

酵母在发酵中已经把氧用尽；此后任何进氧都无法再被去除，只会加速老化和浑浊。

</details>
