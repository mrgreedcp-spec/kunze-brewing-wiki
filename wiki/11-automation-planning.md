# 11 自动化与工厂规划（Automation and plant planning）

> 专题 · Kunze 原书印刷页 p.869–919 · [返回首页](README.md)

今天没人再钻进罐里刷洗，靠的是一整套前提：可远程控制的阀门、固定管道、能 CIP 的设计、足够的传感器和可靠的控制系统。本专题讲测控选型、规划与合同流程，以及卫生、安全、管道设计的要点。

- **范围**：测量与控制系统、规划流程与合同、卫生设计与防混料、管道设计
- **关键数字**：信号 4–20 mA · Ra ≤1.6 µm · 麦汁啤酒 ≤3 m/s

**本页工序**：[11.1 测量与控制系统](#s11-1) · [11.2 规划流程、文件与合同](#s11-2) · [11.3 卫生设计、防混料与安全](#s11-3) · [11.4 管道设计](#s11-4)

## 11.1 测量与控制系统（Measurement and control）

*Kunze p.869–876*

**目的**：从全厂出发选仪表和控制系统：精度够用、频次够用，便于校验和维护，并把 PLC 的需求事先写清楚。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 四类仪表 | 一般运行仪表（相对误差 1–2% 就够）；影响质量的（醪和洗糟水温度、杀菌温度和时间、打压压力、O₂ 和 CO₂、啤酒与麦芽分析）；经营核算用的（能源、水、原辅料，尽量称重）；实验室仪表（有的要每天或每次使用前校准并记录） |
| 标准信号 | 0–10 V 或 0/4–20 mA；4–20 mA 便于查线路：0 mA 即断线，&lt;4 或 &gt;20 mA 可判为故障 |
| 安装与接口 | 耐化学的不锈钢（1.4301、1.4401、1.4541、1.4571）；螺纹、卡箍或张紧环连接，以 DN 50 为主 |
| CIP 适用性 | 完全润湿、自动排气排空、表面光滑（可电解抛光）、耐温 100 °C（蒸汽灭菌时 130 °C） |
| 传压液 | 压力变送器在酒厂用硅油（万一泄漏不会损泡） |
| 手动控制层 | 只能是例外（紧急情况、故障），限定有资格的人（密码）并记录；联锁在手动下也要有效 |

**机理与要点**

- 统一全厂的接口尺寸、量程、测量原理和厂家，能明显降低维护成本；每个测点都要问是否真有必要，有的只在调试时才需要。如今信号变送器已不是最弱的一环，最弱的是调节阀等执行元件。
- 核算用的计量要能互相核对：与送货单比、分项之和与总表比，必要时冗余测量；称重也可用来标定容积计量。仪表要建立台账（以 P&amp;ID 上的测点为基础），用标签注明下次检定日期；规划时就在取样阀、截止阀处预留比对接口，也可借用冷麦汁计量、罐车称重或 CIP 站的仪表来校核。
- PLC 需要的信息：测量值和设定值、各介质（水、压缩空气、CO₂、蒸汽、清洗剂）是否可用、阀门的开关位置、活动弯头等手动连接件的位置和驱动器状态。PLC 的需求书要回答：是否联网和分级、总线标准、集中还是分散、数据采集和归档到什么程度、化验数据是否纳入追溯、检修时如何就地操作等。
- 画面以简化的 P&amp;ID 为基础，用 DIN 图形符号：显示过程值和设定值、当前程序步和剩余时间，用颜色区分阀门和驱动器状态、显示已开通的流路，报警要说清何处、何事、何时；操作站不要因为“节约”而太少。
- 程序可由供货商用模块拼成标准软件包，也可由用户先写出详细的程序描述和功能图、做成“量身定做”的软件（更费事，但调试快、更合用）；双方要组成团队在试运行前测试好程序、配方参数和画面。只归档偏离设定值或公差的数据，避免“数据坟场”；软件架构要开放，分散的 PLC 故障时只停一部分，现场总线能大幅降低安装成本，还要约定售后响应时间和远程维护。

**自测**

<details><summary>为什么变送器常用 4–20 mA 而不是 0–20 mA？</summary>

把量程下限对应 4 mA，0 mA 就只可能是断线，超出 4–20 mA 的信号也能判为故障，控制系统能自动发现线路问题。

</details>

<details><summary>经营核算用的计量为什么尽量用称重？</summary>

质量的测量不确定度最小，不受温度和密度变化影响；称重还可以反过来标定容积式计量。

</details>

## 11.2 规划流程、文件与合同（Plant planning, documents, contracts）

*Kunze p.876–893*

**目的**：按迭代的规划流程推进项目：任务书写完整，招标可比较，合同写清楚，调试和移交有据可查。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 规划流程 | 目标 → 任务书 → 可行性研究 → 初步方案（地点、工艺、规模、布局、供应与处置）与经济性研究 → 询价 → 立项决策 → 详细设计 → 招标与比价 → 合同 → 建设安装 → 培训 → 调试和试运行 → 性能考核 → 正式运行 |
| 四级图纸 | 工艺框图（不受标准约束）→ 基本流程图 → 工艺流程图 → 管道仪表流程图 P&amp;ID（德国按 DIN 28004、DIN 19227） |
| 测点字母 | 首字母：T 温度、P 压力、F 流量、L 液位、Q 质量参数（pH、O₂、CO₂、电导）等；后续：I 指示、R 记录、C 调节、A 报警、S 开关，H/L 为上下限，D 为差值 |
| 绘图比例 | 1:2、1:5、1:10、1:20、1:50、1:100 等标准比例，不用 1:25 |
| 质保期 | 一般从性能考核成功之日开始 |

**机理与要点**

- 规划要纳入企业的中长期规划，不能在时间压力下做；要尽早与审批机关一起梳理适用的法规（环保、建筑、需监管的设备、水法、残余物处置等），环保和技术安全贯穿各阶段。
- 任务书必须精确、完整：遗漏会导致报价不完整，事后补项时成本不成比例地上升，设备也可能运行不好。在此基础上写招标技术说明，让各家在同样的前提下报价：详细描述、企业标准（材料、表面、指定厂家、颜色、安全技术）、供货界限、能力和介质参数、工地规则、工期、保证值（工艺参数、能力、单位消耗等）、文件和培训要求、合同条件。请供货商代写时要确保不偏向任何一家。
- 甲方希望承包方越少越好，可以请总承包商统一协调分包（费用按投资额的一定比例）；国际项目多为“交钥匙”工程。合同要写清标的和条件：价格方式、付款、预付款保函、完工保函、逾期和达不到保证值的罚则、质保、备件供应年限、售后和保险。
- 调试前设备、介质、测控都要就绪，功能试验、清洗和安全检查完成并有检验证书，操作人员经过培训并有手册；用规划阶段就写好的检查表逐项确认（谁、何时、结果）。试运行持续到稳定达到约定参数，性能考核可由双方或中立的第三方进行。只有在“无异议移交”——考核合格、尾项完成、缺陷消除、备件和竣工资料移交、培训签字、款项结清——之后才确认项目结束。
- 项目文件（设计图、手册、材料和焊接证书、压力容器检验、结构计算、许可等）多为孤本，要安全归档、更新为竣工状态（含当前的控制软件），日常只用复印件；工艺说明、配方和操作规程要按明确规则持续更新。

**自测**

<details><summary>任务书写得不完整会有什么后果？</summary>

各家的报价范围不同、无法比较，缺的部分事后要补，成本不成比例地上升，设备还可能达不到预期或运行不好。

</details>

<details><summary>为什么检查表最好在规划阶段就写好？</summary>

写的过程就能发现设计中的遗漏，调试时逐项确认、记录，工厂也能更快达到设计参数。

</details>

## 11.3 卫生设计、防混料与安全（Hygienic design, media separation, safety）

*Kunze p.893–898、909–919*

**目的**：让设备满足自动化和无污染运行的前提，可靠地隔开“敌对”介质，防止超压和负压，并规划好 CIP 站和化学品库。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 自动化前提 | 有工艺算法；全部部件可远程控制；固定管道和阀门；能 CIP；所有相关量有传感器；材料耐腐蚀 |
| 表面 | 接触产品的表面 Ra ≤1.6 µm，最好 ≤0.8 µm；焊缝与母材相当 |
| 焊接 | TIG 手工焊或自动轨道焊，管内充分通保护气（如 90% N₂ + 10% H₂），焊后酸洗钝化；管内回火色很难去除 |
| 材料 | 通用 1.4404、1.4571（AISI 316/316Ti）；1.4301 等（AISI 304）在温度较高、pH &lt;8 且氯离子 ≥50 mg/L 时会腐蚀 |
| 密封 | 用 EPDM（黑色）或硅橡胶（红色）；蓝色 NBR 不耐热 CIP |
| 酸化热水消毒 | ≥90 °C、pH ≤4（防止碳酸盐析出） |
| 化学品库 | 围堰要能容纳最大一个容器的全部内容，或用带泄漏指示的双壁容器；浓烧碱卸料时稀释到约 25%，防止冷却结晶 |

**机理与要点**

- 防混料的三种办法：手动活动弯头（最简单便宜，只在一处连接、不会接错、用传感器监视位置，但不适合自动化）；泄漏阀组“block and bleed”（三只阀、位置受监视，自动化中最经济；缺点是占地大、两阀之间留有液体；无氧操作时要防止泄漏腔自动排空而进气）；双座阀（最实用、可做成紧凑的“阀岛”，但贵；要按用途选防液击型、阀座可提升清洗型或波纹管密封的无菌型，安装方向要让介质压力帮助关闭）。
- 超压和负压的保护要自主，在电、压缩空气或控制失效时仍然有效（例如失气时靠弹簧关闭的执行器）。安全阀按泵的最大流量选口径并定期检验；大罐对负压非常敏感，几毫米水柱就可能出事——成因有排料时没有补气、溢流时的虹吸、罐内物料冷却收缩、CO₂ 被碱液吸收等；锥形罐热 CIP 时要让冷罐保持微正压并监视罐压。
- 取样阀要能无菌取样、不留残液、可冲洗消毒并能 CIP；火焰灼烧只改善表面，对充满产品的阀门并没有真正的热效应，化学消毒更可靠，取样工具要泡在消毒液里。阀门：蝶阀便宜可靠，是水和产品的首选；双座阀是自动化工厂的基本前提；球阀适合水和 CIP；旋塞和闸板已过时。
- CIP 规划：常按作业节奏分设几个站（糖化间含麦汁冷却、发酵成熟与酵母、过滤与清酒罐、灌装），化学品库最好集中；长管道宜用回收式清洗，罐宜用一次性清洗，站里最好两种都能做；CIP 罐容积尽量小；换介质时先把旧介质顶到罐里、再把剩下的旧介质回流、最后才送入新介质；热洗润湿好，能进入缝隙，缝隙和死角里只能靠热杀菌。
- 外表面也要卫生：光滑无缝、液体能流尽、四周满焊，用封端的圆管或方管，不用角钢、槽钢等开口型材，不用带缝夹紧件和内六角沉头螺钉，不许有开口孔和点焊；薄板做压花或喷砂处理不显划痕，抛光面很敏感。

**常见问题**

| 现象 | 常见原因 | 对策 |
| --- | --- | --- |
| 罐在排料或清洗后被吸瘪 | 排料时补气不足、溢流虹吸、热 CIP 后冷却收缩、CO₂ 被碱液吸收 | 留足通气截面，装真空阀和破虹吸孔，CIP 时保持微正压并监视罐压 |
| 产品被清洗液或别的介质污染 | “敌对”管路之间只靠一个阀门隔开 | 改用双座阀、泄漏阀组或活动弯头，并监视阀位 |

**自测**

<details><summary>为什么“敌对”介质之间不能只靠一个阀门隔开？</summary>

单阀一旦密封失效或被误开，清洗液就会直接进入产品；双座阀或泄漏阀组在两道密封之间有排空的泄漏腔，泄漏能被看见并排走。

</details>

<details><summary>锥形罐做热碱 CIP 时为什么要特别注意负压？</summary>

罐里的 CO₂ 会被碱液吸收，热罐冷却时气体还会收缩，都会让罐内压力下降；大罐几毫米水柱的负压就可能被吸瘪。

</details>

## 11.4 管道设计（Pipe design）

*Kunze p.898–909*

**目的**：把管道设计成不留死角、能完全排空和清洗、流速合适、伸缩自由、保温可靠的系统，避免液击和汽蚀。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 规格 | 产品管 DN 10–150，PN 一般 ≤16（视镜等有的只有 PN 6/10） |
| 坡度 | 1–2%；做不到时水平敷设，但要能完全排空 |
| 推荐流速上限 | 麦汁与啤酒 ≤3.0 m/s，去过滤槽的醪 ≤1.5，浓酵母 ≤1.0，泵吸入管冷介质 ≤1.8、热介质 ≤1.0，水 ≤4.0（长管 ≤2.0），液氨 ≤1.6，压缩空气和 CO₂ 10–25 m/s |
| 含 CO₂ 的介质 | 沿程任何一点的压力都不能低于 CO₂ 平衡压力的 1.5 倍 |
| 压降例 | 40 m³/h 水流经 60 m DN 50 管：约 5.7 m/s、约 4.7 bar；换 DN 65：约 3.4 m/s、约 1.3 bar（按列线图，水柱 10 m ≈ 1 bar） |
| CO₂ 吹扫 | 气压要比最大液柱静压高 0.4–1.5 bar |
| 保温 | 锥形罐 ≥100 mm（现多为 120–150 mm），管道 40–60 mm |
| 死角 | 支管长度最好小于管径，截止阀尽量贴近主管 |

**机理与要点**

- 可拆连接：无菌型螺纹活接（两半必须焊得绝对平行，偏差不能靠挤扁密封圈补偿；勾扳手不需用力，要用力就说明装错了）；法兰（优先，装拆简单、能补偿小的安装误差，输送危险介质时要加防喷罩）；卡箍（国际通用）；张紧环（阀门部件和传感器）。
- 温度变化引起的伸缩不能产生应力：用滑动或吊挂支架、补偿器，或留几米长的弯管臂；固定支架的位置要让伸缩对称分布，支架材料与管道相同；变径用偏心大小头；支管水平引出，不留残液和气泡；穿楼板要加套管和挡水罩。
- 流速要兼顾压降（运行成本）和投资，还要保证 CIP 的冲刷作用；剪切对麦汁和啤酒的影响要重视但不必夸大。泵的吸入管必须流速低、压降小，热的、含气的、来自无压容器的介质尤其如此，必要时降低泵的安装高度或抬高罐的出口。
- 液击：阀门开闭太快，动能在瞬间变成压力冲击。90° 转角的蝶阀、球阀很难慢关，气动执行器开时突然、关时最后猛地截断 → 在气管上装可调节流阀；自动化设备最好在无压状态下切换阀门，先开通流路、再用带斜坡的变频器启动泵，停泵顺序相反。
- 除氧：用脱氧水顶替成本高，而且空气饱和的水除不了氧；用 CO₂ 吹扫更便宜，还能同时给管道预压。冷管的保温必须有金属隔汽层（没有真正隔汽的塑料），隔汽层总在温度高的一侧、支架处也不能中断，否则水汽渗入、冷凝，保温就失效了。
- 其他：安全阀、排空和 CIP 排出管要接到容器或下水，不能喷到地上（烫伤、腐蚀）；防冻用伴热或保持流动，排空不净时用气吹；会结晶的介质（烧碱、糖液）要稀释或保温；蒸汽管要定期排出冷凝水，支管从上方引出，冷管慢慢暖管。

**相关工具**：[计算：管道流速与管径](tools.md#pipe)

**自测**

<details><summary>为什么泵的吸入管要比出口管流速更低？</summary>

吸入侧压力本来就低，流速高、压降大就会使压力降到液体的沸点以下，产生汽蚀；热的和含气的介质尤其危险。

</details>

<details><summary>冷管保温为什么一定要有隔汽层？</summary>

空气中的水汽会扩散进保温层，在低温处冷凝，湿了的保温材料导热系数大增，保温就失效了。

</details>
