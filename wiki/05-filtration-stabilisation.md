# 05 过滤与稳定化（Filtration and stabilisation）

> Kunze 原书印刷页 p.453–531 · [返回首页](README.md)

除去酵母和浑浊颗粒，让啤酒在保质期内保持生物、胶体和风味三方面的稳定；从贮酒罐到灌装机，全程不许进氧。

- **输入**：成熟啤酒（酵母最多约 10⁶ 个/mL）
- **输出**：清酒：清酒罐 0–1 °C，途中增氧 ≤0.01–0.02 mg/L
- **关键数字**：硅藻土 80–120 g/hl · 瞬时杀菌 68–72 °C · PVPP ≤50 g/hl

**本页工序**：[5.1 硅藻土过滤](#s5-1) · [5.2 精滤、错流与无硅藻土过滤](#s5-2) · [5.3 生物稳定化](#s5-3) · [5.4 胶体稳定化](#s5-4) · [5.5 风味稳定与防氧](#s5-5) · [5.6 特殊工艺](#s5-6)

## 5.1 硅藻土过滤（Kieselguhr filtration）

*Kunze p.453–473*

**目的**：用预涂层和连续添加的硅藻土截留酵母和浑浊颗粒，同时绝不让氧进入啤酒。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 预涂 | 第一层粗土约 700–800 g/m²（约占 70%），第二层较细的土；合计 800–1,200 g/m²，厚 1.5–3 mm，约 10–15 min |
| 连续添加 | 60–120 g/hl（约 1/3 中等土 + 2/3 细土）；整个过程 80–120 g/hl，最多约 200 |
| 压差上升 | 平均约 0.1–0.3 bar/h（罐式最多 0.5 bar/h） |
| 终止压力 | 板式预涂机 2–5 bar；烛式 6–8 bar |
| 烛式滤机 | 楔形丝缝 50–80 µm，烛芯最长约 2 m，最多约 700 根，无运动部件 |
| 灭菌 | 出口 &gt;85 °C（最好 90–95 °C）后至少保持 30 min |
| 助滤剂 | 硅藻土用于啤酒（湿密度 &lt;300 g/L 较好）；珍珠岩只用于麦汁 |
| 比过滤能力（hl/(m²·h)） | 烛式预涂 4.8–6；板式预涂 3.8–4；纸板 1.5–1.8；除菌过滤 0.8–1.0 |

**机理与要点**

- 支撑网孔（70–100 µm）远大于硅藻（2–4 µm），所以必须先预涂出一层互相支撑的“桥”。压力或流量一冲，桥就断，啤酒立刻跑浑 → 滤前滤后设缓冲罐，恒流运行。
- 添加太少：酵母不能嵌进土层，形成阻挡层，压力陡升；添加太多：曲线平缓，但过早占满滤渣空间；酵母冲击会造成堵塞。
- 1 L 空气（0.5 bar 表压）约含 450 mg 氧，混进 450 hl 啤酒就会让它升高约 0.01 mg/L——所以管道要用脱氧水排空气，用纯 CO₂ 背压，不回收富氧的前后段。
- 前后段（水与啤酒的混合段）含氧、易污染，至少要经过瞬时杀菌（约 28–30 PU）；为了能兑回去，酿造时浸出物要提高 0.2–0.3%。
- 硅藻土粉尘（尤其煅烧后含方石英）可致矽肺：散装入仓、无尘拆袋、戴 P2 面罩、定期体检。

**自测**

<details><summary>硅藻土过滤为什么必须“恒流、无冲击”？</summary>

滤饼是靠颗粒互相搭桥形成的，压力或流量突变会撕裂滤层，浑浊颗粒直接穿过去。

</details>

## 5.2 精滤、错流与无硅藻土过滤（Sheet, membrane, cross-flow）

*Kunze p.473–487*

**目的**：在硅藻土之后进一步澄清或除菌，或者用膜和可再生助滤剂彻底取代硅藻土。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 冷除菌串联 | 精滤约 5 µm → 抛光约 1 µm → 除菌约 0.45–0.5 µm |
| 纸板和模块 | 纤维素 + 硅藻土；分粗滤、澄清、精滤、除菌（EK）等级；越精通量越小 |
| 错流膜 | 中空纤维或陶瓷，孔 0.4–0.8 µm（啤酒常用 0.45–0.65 µm） |
| 典型膜系统 | 每 2 h 或 4–5 h 反冲一次；损失 0.2–0.4%；膜寿命约 4,000 h |
| 连续式错流 | 浓缩液干物质上限约 17–18% |
| 可再生助滤剂 | 例如聚苯乙烯 + PVPP 的颗粒：预涂约 2 kg/m²，连续 50–300 g/hl，兼有稳定作用 |
| 预澄清分离机 | 可减少硅藻土 20–50%，滤机周期约翻倍 |

**机理与要点**

- 取代硅藻土的动力主要是废土处置费和健康风险，而不是土本身的价格。
- 膜过滤的难点：孔径均匀、长期耐压、断丝时能立即隔离、清洗能恢复全部孔（碱加过氧化氢比单用碱效果好）。
- 纸板机效果好，但只能在厂内反洗，占地大、人工多，不耐高固含量和高菌数。

**自测**

<details><summary>错流过滤和死端过滤的根本区别是什么？</summary>

死端过滤让全部液体穿过滤层，颗粒越积越厚；错流过滤让液体沿膜面流过，只有一部分清液透过，截留物被流动冲刷并回流浓缩。

</details>

## 5.3 生物稳定化（Microbiological stabilisation）

*Kunze p.487–493*

**目的**：保证保质期内不被微生物破坏：要么杀死，要么除去所有可能的腐败菌。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| PU 定义 | 60 °C 保持 1 min = 1 PU；PU = 时间(min) × 1.393^(T−60) |
| 所需 PU | 啤酒一般 14–15 PU，污染重时 22–27 PU；罐装啤酒 18–20 PU（最多约 30） |
| 瞬时杀菌 | 68–72 °C 保持约 50 s，全程约 2 min；热回收可达 96%；需最高约 12 bar 的泵压防止 CO₂ 析出 |
| 隧道杀菌 | 约 1 h；能耗 14–24 MJ/hl；瓶内顶隙 ≥4%（0.5 L 瓶约 20 mL） |
| 罐装杀菌温度 | 不超过约 62 °C（罐只耐 6 bar） |
| 常见腐败菌 | 野生酵母（如 S. diastaticus）；Pectinatus、Megasphaera、短乳杆菌、有害片球菌等 |

**机理与要点**

- 温度稍升，所需时间就指数下降：以 15 PU 为例，64 °C 约 4 min，68 °C 约 1 min，72 °C 只要约 17 s——控温必须极准。
- PU 衡量的是杀菌效果，不是风味损伤；风味受损更取决于保持时间和啤酒含氧量。
- 约一半的污染来自过滤后、灌装时的二次污染，所以瞬时杀菌对洗瓶和灌装卫生要求很高。
- 冷除菌灌装避免了热损伤，是趋势；但整条线都要按无菌设计，而且常见泡沫稳定性变差（蛋白酶 A 仍在）。
- 隧道杀菌的冷点在瓶底中央上方约 1.5 cm，温度要在那里测；停机时要有 PU 保护，防止过度杀菌。

**相关工具**：[计算：巴氏杀菌单位 PU](tools.md#pu)

**自测**

<details><summary>隧道杀菌的瓶子为什么必须留足顶隙？</summary>

液体几乎不可压缩，受热膨胀只能压缩顶部的气体；顶隙太小，内压会升到几个 bar，把瓶子撑破。

</details>

<details><summary>为什么说瞬时杀菌只保证了“啤酒本身”的生物纯净？</summary>

它在灌装之前进行，之后的洗瓶、灌装、压盖环节仍可能带入微生物。

</details>

## 5.4 胶体稳定化（Colloidal stabilisation）

*Kunze p.493–504*

**目的**：推迟冷浑浊和永久浑浊的出现：减少蛋白降解物和多酚中的一方，并排除加速它们结合的因素。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 冷浑浊 | 冷却时出现、回温到 20 °C 又溶解；随时间转为不再溶解的永久浑浊 |
| 加速因素 | 温度（影响最大）、氧化（可让浑浊提前约 5 倍）、重金属离子、晃动、光 |
| 硅胶 | 50–150 g/hl；吸附形成浑浊的多肽，对泡沫蛋白影响小；颗粒平均 8–20 µm 最有效 |
| PVPP | 选择性吸附多酚；德国最多 50 g/hl；可用约 85 °C 的 1% NaOH 再生重复使用 |
| 硅溶胶 | 约 30–60 mL/hl，冷贮前加入，与蛋白交联成凝胶后沉降、被完全去除（符合纯酒令） |
| 工艺底线 | 定型麦汁可凝固氮 ≤2 mg/100 mL；过滤前 −2 至 0 °C 冷贮 ≥7 天 |

**机理与要点**

- 冷浑浊是高分子蛋白降解物与高度缩合的多酚（主要是花色苷原）靠氢键松散结合而成，夹带少量碳水化合物和重金属。颗粒在布朗运动中不断碰撞、越聚越大，最后肉眼可见。
- 工艺措施贯穿全程：低蛋白细皮大麦、良好溶解、充分焙焦、残碱 &lt;5 °dH、不做长蛋白休止、完全糖化、不过度洗糟、强力煮沸和充分凝固、酸化到 pH 5.1–5.2、冷而旺盛的发酵、足够的冷贮、全程排氧、不接触裸露的非不锈钢金属。
- 这些措施只能推迟、不能阻止浑浊，所以保质期长的啤酒还要用稳定剂：硅胶去蛋白、PVPP 去多酚，两者可以联用。

**自测**

<details><summary>为什么巴氏杀菌反而会加速胶体浑浊？</summary>

温度升高加快了蛋白与多酚的聚合；杀菌解决了生物稳定，却牺牲了一部分胶体稳定。

</details>

## 5.5 风味稳定与防氧（Flavour stability, oxygen）

*Kunze p.504–509*

**目的**：延缓老化味：从制麦起就控制老化物质的前体，从贮酒罐到瓶子杜绝进氧，并保护成品不受光和热的伤害。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 老化羰基 | 2-甲基丁醛、3-甲基丁醛、苯乙醛等 Strecker 醛，以及脂肪降解产生的醛；阈值极低，在瓶中不断增加 |
| 进氧预算 | 贮酒罐出口 0.00–0.01 mg/L；到灌装机入口最多再增加 0.01–0.02 mg/L |
| 瓶或罐中总氧 | &lt;0.10–0.15 mg/L |
| CO₂ 纯度 | ≥99.998% |
| 日光臭 | 350–500 nm 的光使异 α-酸侧链裂解成硫醇；棕瓶防护最好，绿瓶不足 |
| 麦芽这一端 | TBA &lt;14、库尔巴哈 &lt;41%、凋萎温度低（30–40 °C） |
| 糖化这一端 | 投料 60–62 °C、醪 pH 约 5.2、低氧投料、回旋热保持 &lt;30 min |

**机理与要点**

- 两大前体库：不饱和脂肪酸（脂氧合酶酶解与自氧化）和美拉德产物（焙焦与煮沸中形成）。其中很大一部分在麦芽里就已定型，之后无法降低。
- 老化气味会依次出现：黑醋栗味（严重进氧后几天）、纸板味（脂肪降解）、面包和甜麦芽味（Strecker 醛）、雪莉酒味。
- 氧是头号敌人，但不是唯一原因：很多转化不需要氧，高温贮存和持续晃动同样加速老化。
- 抗坏血酸等还原剂（非纯酒令国家可用）反而会增加羰基生成，不能无限延长保质期；酵母自产的 SO₂ 有一定保护作用。
- 充 CO₂：只有 CO₂ 不足时才做；CO₂ 要极细地分散并有足够的溶解管段，喷气元件必须易于清洗（不要用烧结棒），因为其后已没有过滤。

**自测**

<details><summary>为什么灌装日期比保质期更能说明啤酒好不好喝？</summary>

经过稳定化的啤酒几乎能一直保持清亮，但风味从灌装那天起就在老化；灌装日期直接告诉你它已经放了多久。

</details>

<details><summary>容器预压时为什么用的水也必须先脱氧？</summary>

先充水再用 CO₂ 顶出，水中的溶解氧会进入 CO₂ 气相，随后又溶入啤酒。

</details>

## 5.6 特殊工艺（Special methods）

*Kunze p.509–523*

**目的**：高浓酿造提升产能，冰啤改变口感，脱醇或限制发酵来生产无醇和低醇啤酒。

**关键参数**

| 项目 | 数值 |
| --- | --- |
| 高浓 | 定型麦汁常用 13.5–14.5%；上限约 14.5–15%，再高副产物在成品里可察觉 |
| 节能例 | 300 hl 11% 改成 15% 只需 220 hl，少加热煮沸 26.7% |
| 高浓发酵供氧 | 约每 1% 原麦汁 1 mg O₂/L |
| 过滤后加水 | 成分与酿造水一致、冷到 −1 °C、除菌、完全脱氧、充到啤酒的 CO₂ 含量，并全程按比例加入 |
| 冰啤 | 冷到约 −4 °C 形成冰晶，再结晶长大后分离，用碳酸水调酒度 |
| 反渗透脱醇 | 约 40 bar，啤酒 ≤15 °C；透过液含酒精 1.5–1.8% |
| 透析脱醇 | 啤酒只从 1 °C 升到约 6 °C；某些酯最多损失 65% |
| 真空蒸馏 | 绝压 0.04–0.2 bar，蒸发温度 30–55 °C |
| 无醇啤酒 | 酒精 &lt;0.5% vol；常先脱到约 0.3%，再兑起泡酒或成熟啤酒恢复香气 |
| 中断发酵法 | 原麦汁 9–11%，发酵到 0.5% 酒精（表观发酵度约 10%）后停止，0–1 °C 成熟至少 10 天 |

**机理与要点**

- 高浓的好处主要是稀释水不必加热和煮沸；代价是发酵更慢、酯和高级醇更多，泡沫随稀释变差，回旋沉淀也可能变差。
- 冰啤中部分多酚和多肽随冰析出，口感更顺更圆，泡沫与稳定性通常改善；“冰”指的是工艺，不是饮用温度。
- 所有脱醇方法都会同时带走一部分酯和高级醇，所以要回兑。
- 限制发酵的难点是麦汁味：从 7–8% 的麦汁出发、配 8–15% 浅色焦香麦芽、煮沸不要太短、选合适的酵母。冷接触法在 −2 °C 让酵母还原麦汁味的羰基而几乎不产酒精；固定化酵母可在约 1 °C 连续、可控地生产。

**相关工具**：[计算：高浓酿造节能](tools.md#hg)

**自测**

<details><summary>高浓酿造在过滤后加水，为什么是最复杂的一环？</summary>

这些水直接进入成品：成分、温度、无菌、脱氧、CO₂ 含量都必须与啤酒一致，而且要在整个放酒过程中按比例加入，事后无法纠正。

</details>
